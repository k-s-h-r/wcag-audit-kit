[試験結果](tests.json)はPython67件、Node9件が成功。Nodeはアダプターのモックを含み、Guidepupの実機試験ではない。

[整合性の確認](integrity.json)では、以前の243の記録ファイルと原始証拠が変わっていないこと、全16実行の証拠参照50,167件のハッシュ、86基準の本文・手順、元の下書きZIPを照合した。報告の表示更新などの派生物の変更は別に列挙している。[再集計の記録](report-regeneration.json)でも、以前の件数と完了状況を保持した。

[レポート表示の確認](report-ui-002/results.json)では、1280pxと320pxで2,200行、80の人への引き継ぎ、未完了の表示と残る範囲を確認した。文書幅は各表示幅に収まり、表はスクロール領域に収まった。[通常幅](report-ui-002/summary-1280.png)、[狭幅](report-ui-002/summary-320.png)、[展開した確認票](report-ui-002/human-1280.png)の実画面も確認した。axeの検査範囲は表を除く概要と、展開した確認票1行で、各幅とも違反0件。レポート全体のWCAG適合を証明する試験ではない。

最初の表示確認では全details要素104件をhumanRowsと記録していた。基準ごとの確認票80件だけを数えるよう観察スクリプトを直し、上記の002で確認した。以前の記録と訂正の注記は[report-ui](report-ui/)に保持した。

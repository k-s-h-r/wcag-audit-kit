# 開発時に実行した検証の証拠

ここには実際に取得した証拠を保存している。限定した対象での実証記録と、人による確認を含む通し検証の記録である。確認した範囲と適用上の限界は[VALIDATION.md](../VALIDATION.md)に記す。

- [中間倍率の検証レポート](native-zoom/run-004/report.html)：125%で操作部品が消え、200%で再表示される試験用ページ。実画像・DOM・Tabの証拠を保存した。別の文字拡大方法と全操作の完了が未確認なので、基準全体の判断は保留した。未実施219件・判断保留1件を含む。
- [Chromiumの400%表示](native-zoom/chromium-400.png)：専用Xvfbで実際に拡大したデスクトップ。ブラウザー自身の400%表示を含む。画面の存在だけで内容・全機能を検証済みにはしていない。
- [Guidepupの実行不能の記録](guidepup/blocked.json)：ホストのカーネルとアセットの条件が一致しなかった記録。実読み上げが成功した記録ではない。
- [実際のOrcaの通知・見出し移動](native-orca/README.md)：専用環境で5種類の通知をキーボード操作して比較した。Guidepupとは別の診断であり、全基準の合格を示さない。
- [ACTのタイトル検査の校正](act-title/README.md)：公開18例を実ブラウザーで確認した。タイトルの有無と、実際の主題を説明するかを分け、SVGのルール適用条件も確認した。
- [ポインター取消の校正](pointer-cancellation/README.md)：正常例と押下時に実行する例で、件数・取消・再読み込みを比較した。入力先を間違えた方法の否定例も記録した。
- [ドラッグの代替操作の校正](dragging/README.md)：キーボード代替だけの失敗例と、単一ポインターで動く例を比較し、中間結果の誤りで停止することも確認した。
- [収集の強制停止と復元](recovery/README.md)：実行中の収集器を止め、完了済みの証拠を保ちながら未完了・未訪問・未収集を復元した。正常終了との比較も保存した。
- [表示の向きの比較](orientation/README.md)：向きの画面API・寸法をエミュレーションし、状態を保持して操作できる例と、縦向きで操作が消える例を比較した。実端末の試験とは区別している。
- [媒体の実表示と内容の未確認](media/README.md)：実プレーヤーで3種類の字幕を表示し、時刻・全復号等を取得した。音声入力と試したASRの制約を記録し、内容の比較を判断保留にした。
- [単独ページのAA全基準の通し検査](full-fixture/README.md)：55基準×3状態を通過75・対象外90として範囲内の検査を完了した。比較ページでは4.1.2の3不適合・162未実施を記録し、同じ見た目でも公開状態が異なる問題を報告へ接続した。
- [原典との照合による手順の改訂](procedure-review/README.md)：AAA全31基準と関連する定義等を照合し、媒体の代替を含む10手順を更新した。本文と旧判定を保持し、12実行の再集計も確認した。
- [フォーカス表示の面積と前後の比](focus-appearance/README.md)：実Tabで3種類の表示を比較し、面積不足と前後の変化不足を区別した。2.4.13の通過1・不適合2・未実施255を報告し、G195と本文の相違も記録した。

- [証拠ファイルのハッシュ一覧](proof-manifest.json)：コピーした元の証拠とメタデータのSHA-256。

中間倍率の実行先は証拠の相対パスを保ってコピーした。スキルのルートから次でレポートを再生成できる。未確認が残るので終了コードは2となる。

```sh
python3 scripts/audit.py report --run validation/native-zoom/run-004 --strict
```

これらの試験データを依頼されたサイトの監査結果へ流用しない。新しい環境では、検証方法が動くかを比較用ページで確かめてから対象サイトを調べる。

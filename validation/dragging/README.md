# ドラッグと単一ポインター代替の校正

2.5.7の本文・公式解説、G219・F108に沿い、[移動ボタンのあるページ](../../tests/fixtures/drag-reorder-good.html)と[矢印キーでだけ代替できるページ](../../tests/fixtures/drag-reorder-bad.html)を比較した。2ページ・8収集に加え、各ページの初期状態から4方向を操作する追加probeを実行した。

| 操作 | 移動ボタンあり | キー代替だけ |
| --- | --- | --- |
| Alphaを下／上、Bravoを上／下へドラッグ | 全4操作で順序を変更 | 全4操作で順序を変更 |
| Tabから矢印キーで移動・復帰 | 順序を変更 | 順序を変更 |
| ドラッグなしの単一ポインター操作 | 全4移動をボタンのクリックで完了 | 項目をクリックしても変更せず。他の代替操作もない |

ドラッグの4操作後の表示は、両ページとも`Bravo, Alpha → Alpha, Bravo → Bravo, Alpha → Alpha, Bravo`。正常例の4ボタンも同じ結果となった。各中間結果のassert、実画像、DOM、著者のスクリプト、trusted dragstart/drop、キーボードとクリックのログを照合した。末尾の順序だけを確認する試験にはしていない。

初期状態の2.5.7は通過1・不適合1として記録した。[レポート](run-002/report.html)には残る438件の未実施も表示する。全基準・全サイトの検証完了、又は物理タッチ端末の試験ではない。

対象は2項目の並べ替えだけであり、全2順序を確認した。著者がdropを解釈する機能で、UAが決めて著者が変更しない機能の例外には該当しない。普通の並べ替えにドラッグは本質的ではなく、正常例では同じ結果をクリックでも得た。失敗例のキーボード代替だけでは、2.5.7の単一ポインター代替にならない。

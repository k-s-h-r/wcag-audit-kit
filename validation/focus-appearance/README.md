# フォーカス表示の同一画素・面積の校正

Chromium 156.0.8078.79で、同じ240×80 CSS pxの部品に3種類の著者指定の表示を実際のTabで出した。表示領域1000×700、DPR1、sRGB。実画面と全ソースを確認し、例外と対象一つを照合して2.4.13（AAA）だけを判定した。

| 表示 | 同一画素で3:1以上の面積 | 参考面積 | この基準の結果 |
| --- | ---: | ---: | --- |
| good：4pxの青い輪郭 | 2752 CSS px² | 1280 CSS px² | 通過 |
| thin：1pxの青い輪郭 | 676 CSS px² | 1280 CSS px² | 不適合、面積不足 |
| similar：前後が似た色の4px輪郭 | 0 CSS px² | 1280 CSS px² | 不適合、前後の変化不足 |

goodとthinの前後の比は6.5513048526:1。similarは#005bbaから#005cbbへの変化で1.0134025391:1となった。白とのコントラストが強いことを、同じ画素の前後の条件へ置き換えない。面積測定の補助自体の`wcag_judgement`はnull。

[レポート](run/report.html)は通過1・不適合2・未実施255、範囲未確認、検査未完了。`--strict`の終了コードは2。AAA全86×3の検査票のうち、この方法で確認した3件だけを記録した。axeの違反は全3収集とも0だった。ページ全体又はサイト全体の適合を示す結果ではない。

元の校正とコア収集は別の実行で、前後の全6画像が画素単位で同一であることを確認した。測定はコア収集自身の画像から、実case_idを指定して再実行した。[画像の対応と測定先](run/evidence/methods/focus-appearance/ledger-comparison.json)、[全ソースと実行原文](run/evidence/methods/focus-appearance/)、各ケースの`evidence/attached/`に測定値・指定・画像を保持する。元の校正の指定や証拠を書き換えていない。

Python57試験が成功し、この方法に関する6試験で同一画素と隣接色の区別、DPR²の換算、3未満の丸め禁止、指定領域の限定、不正な値、形状の寸法を確認した。これは既知のソースによる方法の校正で、未知の表示に対する独立した精度評価ではない。

[原典と参考手順の相違](../../references/SOURCE-DISCREPANCIES.md)を記録し、2.4.13の手順を版2へ更新した。全86基準の本文ハッシュは不変。旧12実行の記録・証拠・定義を保持して報告を再集計し、新定義による旧実行への追記は拒否した。

再集計はスキルのルートから行う。

```sh
python3 scripts/audit.py report --run validation/focus-appearance/run --strict
```

測定補助の適用範囲、2pxの境界そのものによる経路、色や形状の取りこぼしの扱いは[フォーカス表示の手順](../../references/focus-appearance.md)を参照する。

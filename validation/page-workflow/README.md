## 結果の限界

この試験はAIサービスへ接続せずに実行した機械検査の確認である。825票のWCAG判定は未記録として残し、機械ルールの結果から基準全体の適合や不適合を生成していない。手続き・意味・目的・必要な実SR等の確認は、実行できる道具から追加し、足りない部分だけ内容判断へ回す。

この試験ページでは、送信と別ページへのリンクを保留した。別ページの受信・書き込みの受信は0件。これらの操作を無かったことにせず、残る検査に示した。任意の本番サイトの副作用を完全に防ぐ保証ではない。

有限の候補・状態・入力を試した結果であり、任意のサイトの全状態を発見した保証にはしない。iframe、closed shadow DOM、canvasの内部や複雑な独自部品等には追加検査が必要。実スクリーンリーダー、Microsoft Excel/Excel Onlineの実操作や印刷は今回の試験に含めない。

## 再現

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tests/page_workflow_browser.py --out /tmp/new-page-acceptance
python3 tests/page_workflow_extra_browser.py /tmp/new-page-extra
python3 tests/page_workflow_report_browser.py /tmp/new-page-acceptance
```

新しい出力先を使う。実ブラウザーの起動とlocalhostへの接続が可能な環境が必要。依存物はrequirements.txtとChromium。公開サイトや外部アカウントは使用しない。アーカイブの既存runから帳票だけを作る場合は、展開したコピーへpage-reportを実行する。再訪問や実SRの起動は行わない。

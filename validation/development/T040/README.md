# 既定24手で子ダイアログへのEscapeを観察する

T038の公開版 `9717ba4` を起点に、`7bdec93` で同梱の2.1.2と2.4.3の対照をループバックで配信した。初期取得と既定の簡易探索を使い、AAA、機械モード、初期画像、24手、16状態、深さ3で比較した。Chromium 156.0.8078.79、Playwright 1.62.0、1280×900と320×900 CSS px。ブラウザーは一つずつ起動した。[収集手順](measure.py) · [判定と経路の照合](verify.py)

## 変更する候補の選定

T036の24手では子が15・16手目に開いた。続く17・18手目でも、親をクリックして子をEnterで開いた。64手のT038で、同じ子へのEscapeは45・46手目だった。探索では最初に見つけた子の状態からEscapeを待ち行列へ追加する。親がすでに開いている場合は、一層のダイアログに使う優先条件が成立しない。[T036の既定手順](../T036/README.md) · [T038の観察](../T038/README.md)

保存済みの状態を使った順序の再現で、先に試す候補と後へ回す候補を比較した。子のEnterを後へ移す案では、既定の手順が残していたキー入力の証拠を後回しにする。親の背景をクリックしたときは、表示が同じ指紋でもフォーカスが本文へ移った。すでにフォーカスがある空の入力欄をクリックしたときは、記録されたフォーカス、表示状態、操作部品が同じだった。後者を待ち行列に残し、その通常優先を各幅で一件ずつ下げる。[設計判断](../../../docs/adr/0124-prioritize-observed-nested-escape.md)

予約の条件は、同じ主文書で開いた親の内側に非表示の子が一つあり、空の通常のテキスト入力欄にフォーカスがあること。登録済みのクリック処理とポインター移動の処理を確認する。再生時は実際に子が開いたと分かる経路にだけ前倒しを適用する。CSSのホバーやブラウザーのスクロールなど、入力欄へのクリックで生じる他の効果は引き続き個別の観察で扱う。

対象の通常8ページは、保存済み76ページの深さ1のクリック後141経路も確認して選んだ。表示モーダルと、非フォームの通常テキスト入力欄へのフォーカス、静かな同一文書、フレームがないことを満たす起点は、039・040・045・046・062・063の両幅にあった。064・065は、過去に24手で閉じるボタンと次のTabが失われた対照として加えた。通常8ページ、再開とクリック処理の追加2ページを新規収集した。[76ページの保存済み採点](../T030/run-003/score.json) · [旧24手の経路](run-001/default-routes.json)

## 既定24手での観察

対象4ページで、PC幅の14手目と狭い幅の16手目に、ブラウザー由来のEscapeが子の `#inner-name` に届いた。次に子をEnterで開く17・18手目と、親を閉じてTabを送る19–24手目を確認した。HTMLとExcelの操作調査で、開閉・フォーカスから証拠へ移れることを照合した。[対象ごとの観察](run-001/results.json)

| 対照 | Escape後に表示されたダイアログ | フォーカス |
| --- | --- | --- |
| 045 | 親と子 | 子の住所入力欄 |
| 046・063 | 親 | 親の子を開くボタン |
| 062 | 親 | ダイアログの外の本文のボタン |

対象4ページでは、元の19件の待ち経路から、実行した子Escapeの各幅1件と、各幅で同じ文字列を親入力へ2回入れる候補が外れた。後者は待ち行列の上限により省略した。親入力をクリックする候補は両幅で待ち行列へ残り、24手の終了時点では17件が残った。039・040と064・065は、既定で実行した経路・待ち行列・次のTabを従来の記録と照合した。両幅の照合と既存の採点12行を再確認した。[候補と採点の差](run-001/results.json)

親子をクリックで開いた状態からの離脱を記録した。通常CLIで親子をキーだけで開く経路は別の検証条件。子の開閉はT038の観察として扱い、達成基準の適否は検査票に残る。[キーだけで開いた個別試験](../T036/README.md)

## 中断とポインター処理の対照

045を6手で中断すると、親の後に順を下げるクリック候補が両幅で未使用のまま保存された。同じrunを24手まで再開し、中断前の証拠40件のSHA-256が一致すること、全24経路が通常runと同じ順序になること、各幅で一度だけ子Escapeを調べることを確認した。文書にクリックリスナーを登録した対照では、元の24経路と待ち行列を再現した。[再開とクリック処理の結果](run-001/results.json) · [初期・再開・各証拠の抜粋](run-001/evidence.zip)

独立レビューでは、祖先に `pointerout` または `mouseout` の処理がある対照と、開くボタンに `pointerleave` の処理がある対照を試した。入力欄をクリックし直すとフォーカスを保ったままマーカーが表示された。修正版で同じ動きを再測定し、マーカーが現れる各対照は前倒しの対象から外れることを確認した。独立レビューは通常8ページ、再開とクリック処理の対照も照合した。[ポインター移動の原始証拠](run-001/pointer-boundaries.zip) · [独立レビュー記録](run-001/independent-review.md)

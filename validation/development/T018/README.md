2026-11-18。公開されたactionsと到達条件assertを、探索で実際に観測した経路・DOM条件と照合して状態を名付ける。設定は操作を実行せず、送信・保存の保留を解放しない。既知の名前が一つあるからと全非初期ノードをまとめる処理は加えていない。

採点へ渡す証拠はaxe・state・transition。操作経路、公開条件の実観測、遷移の成功が一致したときだけ名前付き状態へ対応する。古い未ラベルの証拠、条件の不一致、失敗又は制限通信は未確認とし、同じ状態・対象の矛盾した機械証拠は判断保留にする。複数の可視性を曖昧に判定しない。

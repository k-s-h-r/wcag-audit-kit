# T017：短い関数タイマーとDOM変化を上限付きで観察する

2026-11-18。T009のフォーム外ボタンの修正後も、固定100ms待機で300ms後の画像を取り逃がした。別の650msの専用fixtureでも[修正前の未取得](before-650-observed.json)を再現した。

関数形式のsetTimeoutの予定・実行・取消とDOMの変化を観測し、近い予定がなくDOMが150ms変わらない状態を待つ。1回の観察上限は1500ms。上限外の予定や追跡できない文字列コールバック、継続中の再帰タイマーはbounded又はtimeoutとして残す。各state.jsonとtransition.jsonに待機結果・経過時間・残る予定・観測範囲を保存し、非quietなら探索の残作業にも加える。

[300ms](after-300-observed.json)・[650ms](after-650-observed.json)の実ブラウザーで画像とimage-altの違反を取得した。[3000ms](bounded-3000-observed.json)は画像を取得できず、未確認として残った。静かなDOMをすべての非同期の完了とはしない。interval・ネットワーク・媒体・アニメーションはこの観測の保証外である。

[タイマーの契約確認](timer-contract-003-observed.json)では、コールバック引数とthis、clearTimeoutとclearIntervalによる取消、継続タイマー、文字列コールバックの限界を確認した。data URLの試験は環境のナビゲーション制限で停止したため、設定を変えず所有するHTTPページで試した。再帰タイマーはdeadline直前に次の予定が窓の外へ出てboundedとなる場合もあり、timeoutだけを要求していた確認コードを修正した。両方とも未完了であり、製品の成功へ変更していない。2回の原エラーも保存した。

Python208試験と[フォーム関連付けの既存回帰](formless-regression-001-observed.json)も成功。4スキルへ同期し、問題集・正解・旧runは変更していない。

[元の画像の新規run](image-001/summary.json)では、7行の成績は5一致・2未確認のまま。しかしc09のclick後にはimage-alt違反、c10のclick後には通過の生データが実際にある。取得の不足を解消した後、現行採点が初期ノードしか読まない別原因が確定した。単に全非初期ノードへafter-loadと付けると、複数回クリックで画像を追加した別の状態まで混ざるため行わない。

T018で公開された操作経路と観測条件を使い、名前付き状態と証拠を対応させる。T017の短いタイマーの取得確認は完了したが、親T009とG1は未達。各zipには修正前後の原始証拠を保存した。全ページ・全将来状態の網羅やWCAG適合を主張しない。

## 見つかった問題と、残った箇所

- **検出した8行**は、初期表示と追加表示の代替文不足（1.1.1、2行）、初期表示とボタン有効化後の文字コントラスト（1.4.3-01、2行）、タイトルなし（2.4.2、1行）、ダイアログをクリックまたはEnterで閉じた後のフォーカス（2.4.3、2行）、ページの言語指定なし（3.1.1、1行）。
- **キーを送れたが機能の判定がない。** 数量変更の `031`（2.1.1、c02）では、両幅で初期の数量は0、クリック後は1、Enter後は0だった。機械の帳票は「Enterを送出した」と報告した。到達と送出の観点は一致し、数量変更の観点は判定なし。実行結果の比較を[T024](../../../docs/tasks/T024-keyboard-function-result.md)へ渡す。
- **必要な経路を確認できない。** `064` のダイアログではクリックとEnterで閉じた後のTabまで記録できた。Spaceで閉じた後のTabまでの証拠はなかった。フォーカスだけでページが移動する `073` では、移動先への通信を制限した記録と、その後の入力待ちのタイムアウトが残った。ページの帳票生成は完了し、3.2.1の行は未確認。
- **採点行と一致しない指摘**は、表示幅・状態別に14件、ページ・基準・検査名・対象でまとめると5組。追加された画像の別セレクターが3組、別の文字コントラスト観点やレベルの対象が2組だった。1.4.3-02の画素計測対象と1.4.6のAAA対象では、同じ対象の低いコントラストを1.4.3のaxeで報告していた。いずれも該当する観点の指摘としての照合は未確認とし、主成績には加えない。

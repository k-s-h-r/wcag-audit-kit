# T019 非表示の aria-controls 参照先を操作後に再検査する

同じボタンに `aria-controls="reference"` を設定したローカルの3ページを、PC相当1280×900とスマートフォン相当320×900 CSS pxで測る。操作用のボタンをクリックすると、画面外にある非表示の参照先を追加・削除するか、同じIDの要素を別の領域へ移す。参照元のHTMLと可視状態は共通。

簡易探索は共通の設定で `page-audit --initial-only` と `--resume --quick-explore` を使う。比較する全文書検査は `--explore` を使う。全文書側には同じクリックと参照先の個数または配置だけを公開の `exploration_labels` で指定する。発見した経路をラベルで確認し、可視状態が同じ場合もその操作後のaxeを保存するための設定。両方のクリックに、入力ログでブラウザー由来のイベントを確認する。

比較する項目は全ルールの違反・判断保留・通過・対象外、各分類の対象と影響度、参照元のHTMLと参照先の有無。再検査数はaxeの結果に記録された対象数で、処理時間とは別に扱う。

## 再実行

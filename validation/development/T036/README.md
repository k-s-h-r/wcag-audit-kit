# T036 入れ子のダイアログの通常探索と明示操作

問題集2.1.2の045（`p07.html`）と046（`p08.html`）を対象にした。どちらも同じ主文書で `role="dialog"` と `aria-modal="true"` を使う二層の対照。起点は公開T030の `9fcaa0d94fb309e49dc7096231760cdddea71b9a`。Chromium 156.0.8078.79、Playwright 1.62.0、1280×900と320×900 CSS pxで測定した。二つのrunには同じHTMLをコピーし、試験前にSHA-256を記録した。[T036](../../../docs/tasks/T036-observe-nested-dialog-exit.md)

## 通常のURL探索

`run-001-normal` は、通常の `page-audit --initial-only` と `--resume --quick-explore` を使った。T020と同じAAA・機械モード・初期画像、累計24ステップ、16状態、経路の深さ3。各検査に渡したのは公開URLと共通の実行設定。045と046とも初期取得と探索が終了した。

両幅で親のボタンをクリックし、子のボタンをクリックまたはEnterで操作した。クリックで子を開いた後の30回の補助Tabは、すべてブラウザーの信頼された入力が同じ主文書に届いた。045は建物と住所の二つの入力欄を循環した。046はその二つと閉じるボタンを循環した。いずれも親子をキーだけで開く経路までは実行されなかった。

24ステップ終了時に、親と子をクリックしてから送るEscapeは両ページ・両幅で待ち行列に残った。保留は各ページ19経路で、問題集の2行は `observed_no_verdict`。既存の観察は閉じる前にモーダルを一つに特定し、離脱後には開いているモーダルがなくなるかを見る。子だけ閉じて親が残る場合を扱うには、閉じた層の観察が必要になる。

## 明示した実ブラウザー操作

`run-002-browser` は各経路を新しいブラウザーコンテキストで開始した。Tab、Enter、Tab、Enterで本文から親を開き、続けて子を開いた。指定URLのGETを許可し、同じ文書のまま遷移したことを各操作の前後で確認した。8経路でキー140回とマウス4回を記録し、どの入力も対象の主文書で `isTrusted: true` を確認した。

| 対照 | 子で観察したこと | 親と本文で観察したこと |
| --- | --- | --- |
| 045 | TabとShift+Tabで二つの入力欄を循環。どちらの入力欄でもEscape、矢印キー、Enter、Space、Backspaceの試行中は子の中にとどまった。マウスで閉じるボタンを使うと子が閉じた | 親は表示されたままで、フォーカスは親の `#inner-opener` へ。親でEscapeを押すと本文の `#launch` へ戻り、次のTabで `#outside` へ移った |
| 046 | TabとShift+Tabの循環に子の閉じるボタンを含む。子の入力欄でEscape、Tabで到達した閉じるボタンでEnter、同じボタンのマウス操作の各経路で子が閉じた | 親は表示されたままで、フォーカスは親の `#inner-opener` へ。親でEscapeを押すと本文の `#launch` へ戻り、次のTabで `#outside` へ移った |

いずれも両画面幅で同じ挙動だった。子からの離脱の手段、子と親それぞれの開閉、実際に戻った位置は個別の観察として記録した。通常CLIの採点と、明示操作で得た観察を個別に参照できる。2.4.3の復帰先の適切さと達成基準全体の適否は追加確認に残る。[観察を製品へつなぐ範囲](../../../docs/adr/0120-observe-nested-dialog-exits-by-layer.md)

別担当が通常CLIと明示操作を別の環境で再実行し、通常採点、子の循環と離脱、親の離脱と復帰先を照合した。子を開いた時点の画像は、同じ表示幅なら2ページと各経路でバイト単位で一致した。通常の原始証拠、明示操作の前後24枚の画像、別担当の確認記録をZIPに収録した。同梱の `sha256.json` で137ファイルを照合できる。ZIPのSHA-256は `265fb410603ab82d03347629de93ab96277cd93199830c5463c280bd4de4d5ea`。[原始証拠のZIP](proof.zip)

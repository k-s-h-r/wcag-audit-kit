# 複数ページの検証から人への引き継ぎまで

所有する5ページの試験サイトで、調査・設定・実操作・各基準の判定・人への具体的な確認票・修正担当向け報告まで通した。利用者が基準番号や方法を選ぶ操作は必要としない。原文・コード・期待する動作を知った状態での受入試験で、未知の業務サイトに対する独立した精度評価ではない。

[HTMLレポート](run/report.html)、[修正担当向け記録](run/issues.md)、[人への確認票](run/human-review.md)、[JSON](run/report.json)を保存した。

| ページ | Home / Profile / Media / Help / Loginの5文書 |
| 状態 | 匿名、dialog、入力エラー、確認、戻る、完了、認証エラー・成功、字幕、再生終了を含む20 |
| 環境 | 1280pxと320px |

| 不適合 / 人による確認待ち | 16 / 80 |

16不適合はHomeとMediaの2.4.5で、状態と表示幅ごとに記録したもの。UI上でそれらを探す経路が共通navだけで、検索・利用者向けサイトマップ・本文の関連リンク等がなく、プロセス段階だけの例外にも該当しなかった。検証対象アプリは修正していない。

80の確認待ちは、同じ対象でも状態・表示幅ごとの検査票として数える。Mediaの字幕・代替・音声解説・音声の指示・映像内の文字・字幕間隔・閃光、HomeのSVG文字拡大、Login成功通知の支援技術サポートを具体的に引き継いだ。元の媒体・各状態・必要な比較・判定条件・結果の戻し方が確認票にある。人の確認待ちを通過へ数えていない。

## 実行した操作と観察

- 全サイトマップ、共通リンク、全サーバールート、HTML/CSS/JSを調査した。`main/name/email`は静的アンカーと確認し、同一文書の別名5件として記録した。ハッシュで画面が切り替わるルートを一律に削除していない。
- 実キーで入力エラー→修正→確認→戻る→再確認→保存を完了し、入力値の保持と受領結果を比較した。
- 実クリップボードとCtrl+Vによるtrusted pasteを取得し、認証成功まで通した。第三者のパスワードマネージャーの試験ではない。
- 実200%・400%、4文字間隔の同時上書き、狭幅でも全主要フローを完了した。実拡大はDPR2/4、表示幅640/320を計測し、スクロールの画面も保存した。
- mouse/keyboard/touchを混ぜてカウンターを操作し、取消・dialogのEscape・ブラウザーUIへの退出と復帰も確認した。タッチはChromiumのエミュレーションで、物理端末ではない。
- 全5ページで4向きの画面・viewport・Orientation APIを計測し、操作と値の保持を確認した。
- 実Orcaで図の代替名、スキップ、見出し、表の行列見出し、入力名・必須・invalid・エラー、カウンター、動画のPlaying/Pausedを取得した。Loginではalertを取得したが成功通知の発話は取得せず、AXの公開値と併記して人へ残した。
- 文字間隔変更のHelpは文書幅329pxとなった。実ArrowRight/LeftでscrollX0→9→0と全文を確認し、横スクロールと内容の損失を区別した。通常の320pxと実400%では横overflowはなかった。

[実行原文・全観察](run/evidence/methods/)と[基準別の初回レビュー](run/evidence/criterion-review.json)を保存した。各caseの現在の判定が最新で、後で不適合の再現手順を具体化した履歴も保持している。runtimeのソケットと生成キャッシュは証拠として配布しない。

全5ページのナビゲーションを実Tab・EnterでたどったURLと、パスワードの表示・非表示をEnter・Spaceで切り替えた属性・AX・画面・値の保持も[追加の操作記録](run/evidence/methods/navigation-password/)へ保存した。検査票は2,200件、改訂前も保持する判定ファイルは2,293件。[報告表示の最終確認](../release-checks/README.md)も参照できる。

## 検証方法の失敗も保持した

[method-controls](method-controls/)には、初回のパス式の誤り、dialogのTabがCloseを循環するとの誤った期待、その診断を残した。Tab→ブラウザーUI→Shift+Tabで復帰→Escapeで閉じる動作を、ページの不適合へ変換しなかった。記録処理で2.4.4の定義漏れを検出した際も、未実施を保持して停止し、全55定義の検査を追加して履歴を残して再開した。

## 完了の意味

全票に判定又は具体的な引き継ぎがある。人の確認が必要な支援技術サポートや動画の非干渉等は未確定で、`audit_complete=false`、`scope_confirmed=false`、`--strict`は2となる。AIの作業を終えたことと、サイトの検証完了・WCAG適合は区別する。

AAA31基準は目標レベル外として未検証を表示する。未知の複雑な部品、外部サービス、別OS・物理端末等では、そのプロジェクトで方法を試し、信頼できない部分を人へ引き継ぐ。

```sh
python3 scripts/audit.py report --run validation/site-acceptance/run --strict
python3 scripts/audit.py pending --run validation/site-acceptance/run --status human
```

この試験のアカウント・パスワード・cookie・プロフィールは全て所有する一時サービスのテスト用データ。設定の認証ファイルの絶対パスは当時の記録として保持する。再実行では自分の起動先で認証・状態を作り、新しいrunを用いる。

# 操作による動きとreduced motionの比較

実キーTab/Enterから装飾の四角を動かし、実時間で3回の位置・画面・アニメーションを取得した。Chromiumのno-preference/reduceをそれぞれ明示し、`matchMedia`の一致を確認した。

| 例 | no-preference | reduce |
| --- | --- | --- |
| good | x=55.006→73.001→88.997と移動 | x=43のまま |
| bad | x=53.006→66.994→83.002と移動 | x=55.000→71.004→86.988と移動 |

全4実行でCountは1に増え、ボタンに焦点が残った。四角は装飾で、動きを止めても情報・機能を失わない。badには他の無効化経路がないことを全ソースとUIで確認し、本質性の例外も適用していない。時計を進めるAPIや、検査器によるCSSの無効化は使っていない。

2.3.3（AAA）を通過1・不適合1として[報告](run/report.html)した。残る170票は未実施で、全AAA又はサイト全体の適合を示す試験ではない。OSの物理的な設定ではなくChromiumのエミュレーションであり、任意のcanvas・動画・他OSの検証能力を保証しない。

[全観察と実行原文](run/evidence/methods/)を保持している。対象サイトでは[検証手順](../../references/reduced-motion.md)に沿って全対象と無効化経路を調べる。

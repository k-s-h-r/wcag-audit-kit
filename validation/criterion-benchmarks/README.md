## 実ページの挙動と実SR

[ページの動作確認](fixtures-observed.json)では、ポインターとEnterによる数量変更、モーダルを閉じる操作、2ページのナビゲーションの順序、字幕トラックの表示状態を実Chromiumで確認した。hiddenの字幕トラックでもactiveCuesを取得できることを確認し、表示とデータの有無を分けた。公開サーバーから正解やディレクトリ一覧を取得できないことも確認した。この試験はページ自体の動作確認であり、検出器の検出成功数へ加算していない。

4.1.3の2例は、専用workerから実Orca 48.1を起動し、ボタンへの移動・操作・画面の更新と発話ログを取得した。今回の環境では、対照となる通知発話を確認できず、2例ともcant_tellとした。画面にあるroleから実発話を推定していない。記録はOrcaの発話ログで、音声の録音ではない。[workerの出力](native-final.stdout.txt)と、proof.zip内のattachments・reviewsに保存している。

## 中断・再開と比較

別の2.4.2・4モードのrunをSIGINTで中断し、同じ実装・環境で再開した。

- 完了済み4ページは再実行せず、同じ保存先を保持した。
- 中断した1ページは別のattemptへ記録し、前の試行を保持した。
- 中断前に固定した678ファイルのバイトは変わらなかった。
- 12ページの完了後、もう一度再開しても試行は増えなかった。途中の試行を含め13件。
- 再採点の比較は新しい回帰なし。未確認を含むため、全体は未完了のまま。
- `score --strict`は終了コード2となり、必要な未確認がある実行を成功にしなかった。

## 原始記録を参照する

[proof.zip](proof.zip)には5実行分の8,421ファイルを、ロックファイルを除いてバイトを変えずに保存した。[archive-manifest.json](archive-manifest.json)で全ファイルのハッシュを確認できる。実装・スキル・手順・原典のスナップショット、DOM・AX・axe・画像・操作経路、採点、実SRの原始ログを含む。

```sh
python3 -m zipfile -e validation/criterion-benchmarks/proof.zip /tmp/criterion-proof
```

summary.jsonのrunとreportを組み合わせると、展開先のHTMLへ進める。例は`/tmp/criterion-proof/実行名/reports/ID/result.html`。証拠リンクは元のrun内で有効になる相対パスのため、HTMLはそのディレクトリ構造で参照する。

通常収集の環境はLinux 6.18.57、Python 3.12.14、Playwright 1.62.0、Chromium 156.0.8078.79。モード・実行上限・対象・各ファイルのハッシュは各runへ記録した。収集後の帳票は、判断保留の試行と確定結果の件数が区別できる表記で再出力した。採点のロジックと正解は保持している。

この問題集を全てクリアしても、未知のサイトでの一般的な精度やWCAG全基準の適合は保証しない。7基準の未収録パターン、未整備の79基準、独立した正解確認、実際のAI判定と通知発話を取得できる実SR環境での精度評価が残る。

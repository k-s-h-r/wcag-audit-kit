# 原典との照合による検査手順の改訂

AAAの全31基準について、勧告の本文・条件・例外・注記と現在の検査手順を照合した。関連する公式解説、用語の定義、G5・G56・G184・C21・G188等も確認した。これは検証知識のレビューであり、全31基準を実ページで検査済みにした記録ではない。

10基準の手順を改訂し、版を更新した。[変更した項目と保存済みの実行の確認](review.json)に、変更前後の版・変更フィールド・本文のハッシュ・各実行の件数を保存した。

| 基準 | 改訂した内容 |
| --- | --- |
| 1.2.1・1.2.3・1.2.8 | メディアに対する文章の代替は、正しい順序の映像・音声情報に加え、時間に基づく操作の結果へ到達する経路も含む。採用した代替の経路に応じて検査し、音声解説と文章の両方を一律に必須にしない |
| 1.4.7 | 適用する音声の条件、背景音なし・消せる・20dB差の別経路、1〜2秒の単発音を分ける。主音声と背景の識別、測定基準と区間も確認する |
| 1.4.8 | 2文以上のブロックという定義、利用者が使える調整経路、80文字・CJK40文字、両端揃え、行間・段落間隔、最大化したviewportでの200%を具体化する |
| 2.1.3 | Aの2.1.1で例外になる軌跡依存の機能もAAAでは調べる。レベルの表記を訂正した |
| 2.2.3 | 非インタラクティブな同期メディアと、定義に沿うリアルタイムイベントの例外を特定する。Aの本質的な時間制限や20時間超の例外、延長できることだけをAAAへ流用しない |
| 2.3.2 | 任意の1秒間の回数を連続した提示から確認する。Aの2.3.1の面積・一般／赤色閃光閾値による代替をAAAへ流用しない |
| 2.4.12 | 作者の内容で一部でも隠れるかを確認する。AAの「全体が隠れなければよい」と区別する |
| 3.3.5 | 明確なラベル、表示済みの説明、UAによる説明も文脈に応じたヘルプとなる。別のヘルプを開く操作だけを必須にしない |

1.4.7のG56は例に平均RMSを挙げ、TestsではdB(A) SPLの測定を記述している。デジタル音声全体の平均値だけを主音声と背景の差としたり、dBFSを物理的なSPLと同じ測定としたりしない。採用する方法が同じ条件を評価できるか確かめる。背景を消せる等の別経路も原典に従って選べる。

1.4.8の「on a full-screen window」は、定義上、一般的なデスクトップ／ノートの表示でviewportを最大化した状態。ブラウザーのUIを隠すF11だけを必須にする意味ではない。段落の間隔は行の位置関係と公式解説・技法を照合する。`margin`又は`80ch`というCSS値の存在だけで判定しない。C21の例・Testsにある1.5〜2という値を、本文にない上限2の追加要件へ変えない。

3.3.5の公式解説は、ラベルで全機能を十分に説明できる場合や、明確なラベル自体がヘルプとなることも説明している。表示済みの説明で必要な情報が得られるページへ、余分な操作を新設するよう要求しない。

勧告本文と公式解説の原本は変更していない。全86基準の本文ハッシュは不変。保存済み12実行は当時の定義から再集計し、件数・完了状況・判定と証拠を保持した。新しい定義による書き込みが旧実行へ混ざらないことも確認した。旧報告には現在の検査定義との差を表示する。

改訂後のPython51試験は成功した。追加・修正した検査方法について、実際の対象がある比較ページでの校正と、複雑なサイトでの通し検査は引き続き必要である。

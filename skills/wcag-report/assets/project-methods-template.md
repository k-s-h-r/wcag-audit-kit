# このプロジェクトの検証環境

実際に調べて操作した情報を記す。手順を用意しただけの項目は未実行とする。

- 手順の版、確認日、作成済み／実行確認済み／再確認が必要な範囲。
- 対象ビルド、起動コマンド、ディレクトリー、利用可能になったことの確認。
- 認証、権限、テストデータ、セッションの扱い。
- 接続先のバージョン・URL・データを読み取りで確認する方法。
- 全ページ・状態への到達方法と、各状態の確認方法。
- 機能ごとの前提・到達経路・操作・観測できる終状態。WCAGの期待結果と操作手順を区別する。
- キー、ポインター、拡大、文字間隔、向き、媒体、支援技術等の使用可能な道具と具体的な操作。
- 操作と結果の証拠を取得・保存する方法。
- 失敗時に既知の状態へ戻す方法。
- 起動したプロセスと試験データの後片付け。証拠は残す。
- 1経路を最後まで実行した記録と、手順自体に残る未確認。
- 後片付け後にも読める証拠と、対象・ビルド・環境との対応。
- 手順と画面の不一致、ツール・環境の不足、対象の機能の問題の切り分け。原因が不明なら未確認。
- 同時操作を避けるブラウザー・認証・試験データの単位と、担当の分け方。
- 実行できない方法、試した結果と証拠、人に必要な環境・対象・操作・判定条件。人への引き継ぎで終える範囲も具体化する。

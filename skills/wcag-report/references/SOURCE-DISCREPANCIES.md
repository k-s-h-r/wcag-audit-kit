# 原典と参考手順の間で確認した相違

参考手順を使う場合も、最終的な判定は採用したWCAG勧告の本文・定義・例外と照合する。原文を都合よく修正して保存せず、相違点と採用した根拠を別に記録する。

## G195のTestsと2.4.13の面積

2026-11-14に[公開G195](https://www.w3.org/WAI/WCAG22/Techniques/general/G195)を確認した。Testsは1 CSS pxの境界相当、又は短辺に沿う4 CSS pixelsの面積を記述している。同梱した固定コミットのG195も同じ内容だった。

[WCAG 2.2の2.4.13本文](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#focus-appearance)は、未フォーカスの部品又はサブ部品の2 CSS pxの外周相当の面積と、フォーカス前後の同じ画素の3:1以上を要求する。[公式解説](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html)も2 CSS pxを説明する。

G195のチェックだけを通過したことから、2.4.13を自動で通過にしない。2.4.13では本文の2 CSS px相当の条件、同じ画素のコントラスト、適用する例外を確認する。可視性や隣接色の観察に参考手順を使った場合も、どこを確認できたかを分けて記す。相違が生じた理由や、修正予定は確認していない。

同じ画素の比較は、1.4.11の隣接色との比較とは別の条件。幅が1pxでも大きく離れた輪郭等は面積が足りる場合があるため、線の太さだけで結論を出さない。2pxの輪郭・境界そのものを用いる経路と、他の形の面積を比較する経路も公式解説に沿って区別する。

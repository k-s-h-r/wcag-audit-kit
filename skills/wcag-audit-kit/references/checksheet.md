# 人向けの達成基準チェックシート

HTMLの主な表とExcelの先頭シートで、達成基準ごとの結果を確認する。国内でよく使われる「達成基準・レベル・適用・適合・注記」の形に、確認観点、不適合箇所、残る確認、証拠への参照を加えている。

## 行の読み方

「基準全体（出力範囲）」は、1.1.1などの達成基準ごとの集計。通常はWCAG 2.2の現行86基準を番号順に表示し、目標レベル外も明示する。削除された4.1.1は含めない。

その下に、保存済みの対象について、同じ期待結果を確認した記録をまとめた内訳を置く。1.1.1の「情報画像の説明」と「操作部品の名前」を記録していれば別々の行になる。同じ観点の対象が複数あれば、その範囲の結果を集計する。期待結果は完全一致でまとめ、意味が似ているだけの文言を推測で統合しない。

内訳の適合は、実際に記録した対象に限る。まだ列挙していない対象や別の観点まで通過した意味にはしない。検査手順の操作を一つずつ必須要件へ変換したり、未実施の観点を適合で埋めたりしない。観点を分けて記録する方法は[判定の記録](recording.md)を参照。

| 適合欄 | 意味 |
| --- | --- |
| ○ 適合 | 出力範囲に含まれる記録が通過し、該当する未実施・判断保留・未網羅や収集の不足がない |
| × 不適合 | 少なくとも1件の不適合がある。残る確認があれば併記する |
| — 非適用 | 全記録で適用対象がない等の根拠を確認した。未実施とは区別する |
| 未確認 | 未実施・判断保留・未網羅・未収集、又は検査票の不足がある |
| 目標レベル外 | 設定したレベルでは検証しない基準。非適用とは区別する |

適用欄には、適用対象を確認した場合は「あり」、全件非適用と確定した場合は「なし」、未確定なら「未確認」を表示する。判定未確定の対象について、適用の有無まで推測しない。人の確認待ちも未確認へ残る。

## 不適合箇所を調べる

不適合のある行には箇所IDとURL・状態・環境・対象要素を表示する。HTMLのリンクとExcelのセルのリンクから「不適合箇所」へ移動できる。一覧には、対象ごとの観察、期待結果、実行した再現手順、同じ検査票の残る確認、証拠・判定記録を全件出す。

多数ある場合、チェックシートのセルは先頭3件と残件数を表示する。不適合箇所の一覧には全件を保持する。注記・残る確認・証拠参照も、要約した場合は残件数と参照先を示す。各検査票・判定記録に全文がある。Excelの文字数・行数の上限を超える場合は黙って切り捨てず、出力を止めて分割を求める。

## 出力する範囲

HTMLはrun全体を集計する。Excelの人向け2シートは、`--page`や`--page-exact`で選んだページの範囲、`--criterion`で選んだ基準、又は`--task`・`--owner`・`--pending-only`で選んだ検査票だけを集計する。範囲をシート冒頭に明示し、除外したページの不適合を混ぜない。タスク・担当・未完了票の出力では、含まれる基準だけを表示する。

タスク等の選択票だけの出力では、まだ作られていない票や収集されていないページを集計に含めない。ページ又はrun全体のチェックシートへ戻って確認する。既存の概要・達成基準シートはrun全体の情報なので、人向けシートの選択範囲とは区別する。

run全体の範囲確認、操作・状態の調査、検証完了の状態も冒頭に表示する。記録した範囲の基準が通過していても、未探索の操作や未確認の適合要件を含むサイト全体の適合を意味しない。

Excelのチェックシートと不適合箇所はreport・workの両モードで閲覧用。見出しを固定し、フィルターと印刷見出しを設定する。判定は色だけでなく文字でも表示する。編集内容を取り込むのは、既存の作業用シートだけ。[共同作業の手順](collaboration.md)に従う。

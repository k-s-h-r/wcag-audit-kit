# 2.2.1に関係するACT Rules

適用条件・期待結果・前提・支援状況・用語を、使用するルール本文で読む。ページの対象へ具体化して実行する。
承認済みを優先する。提案中のものを使う場合はその状態と版を記録する。廃止されたルールは検査の根拠にしない。
ルールがこの基準より厳しい場合や、合格後も追加検査を要する場合がある。下記の対応と原典を照合し、合否を機械的に基準全体へ変換しない。

## bc659a — Meta element has no refresh delay

状態：承認済み。種別：atomic。
[本文・具体例](../sources/act/rules/bc659a.md) / [公開ページ](https://www.w3.org/WAI/standards-guidelines/act/rules/bc659a/)

この基準との対応（原文）：

```json
{
  "forConformance": true,
  "failed": "not satisfied",
  "passed": "further testing needed",
  "inapplicable": "further testing needed"
}
```

この版の具体例：15件。ID・期待値・URLは `python3 scripts/audit.py rule --id bc659a` で参照できる。

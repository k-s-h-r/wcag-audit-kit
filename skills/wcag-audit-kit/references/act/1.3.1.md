# 1.3.1に関係するACT Rules

適用条件・期待結果・前提・支援状況・用語を、使用するルール本文で読む。ページの対象へ具体化して実行する。
承認済みを優先する。提案中のものを使う場合はその状態と版を記録する。廃止されたルールは検査の根拠にしない。
ルールがこの基準より厳しい場合や、合格後も追加検査を要する場合がある。下記の対応と原典を照合し、合否を機械的に基準全体へ変換しない。

# フォーカス表示の面積と前後のコントラスト

2.4.13（AAA）は、同じ画素のフォーカス前後で3:1以上となる表示領域と、その面積を確認する。1.4.11の隣接色との比較だけでは確認できない。[本文と公式解説](sources/2.4.13.md)を読み、適用する例外と全ての部品・サブ部品を調べる。

[G195の記述と勧告の相違](SOURCE-DISCREPANCIES.md)も確認する。G195のTestsの1pxを、そのまま本文の2px相当の代わりにしない。

## 実際のページから測定対象を確定する

1. URL、状態、ブラウザー、拡大率、表示領域、DPR、スクロール位置を記録する。著者指定の表示か、UAの例外を適用できるかを確認する。
2. 未フォーカスの部品の矩形・形状と画面を保存する。実際のキー操作で部品へ移動し、フォーカスが文書内にあること、表示された輪郭等を画面で確かめる。直接`focus()`しただけでキー操作を済ませない。
3. 同じ表示領域・位置・寸法で前後を撮影する。移動、拡大、アニメーション、別の内容更新が混じる場合は、それを解決するか別の検証済みの方法を調べる。差分画像の全画素をフォーカス表示とみなさない。
4. DOM・CSSと実画像から、どの画素が表示のどの部分に対応するかを特定する。線・面・影・隣接する文字等を混同しない。グラデーションやアンチエイリアス等を一部の色だけで取りこぼした場合、その部分を未測定とする。
5. 同一画素の前後で3:1以上となる面積をCSS px²へ換算し、本文と公式解説の面積条件に照合する。全対象について繰り返し、確認できた条件と残る確認を記録する。

## 同梱の測定補助

[focus_measure.py](../scripts/focus_measure.py)は、位置が変わらない部品と、領域・色を特定できた表示を測る補助。Python 3.11以降と[追加依存物](../requirements-analysis.txt)が必要で、Python 3.12で確認した。コアCLIの要件とは別。

```sh
python3 -m pip install -r requirements-analysis.txt
python3 scripts/focus_measure.py --request <このcaseの測定指定.json> --out <新しい出力先>
```

[指定例](../assets/focus-measure.example.json)を、対象ページの実際の値で埋める。画像パスは指定ファイルの場所を基準にする。`case_id`を実際の検査票に合わせ、色と領域を表示として識別した根拠を`mask_description`へ記す。

前後の画像は、同じ寸法の不透明な8-bit RGB/RGBA PNGとする。この補助はsRGBを前提にするため、ブラウザー・撮影方法の色空間を確認する。ICCプロファイル付きや透明な画像は、検証済みの合成・色管理の方法が必要となり、この補助では拒否する。単に`color_space`へ文字列を書くだけで色空間を確認したことにはならない。

指定領域の中から、フォーカス時に指定した実色と一致する画素だけを抽出し、同じ座標の前の色との相対輝度比を計算する。3:1未満を丸めて3にしない。面積は該当するデバイス画素数をDPR²で割る。座標と寸法はCSS pxで指定する。DPRや画像の縮小率を推測して埋めない。

長方形の参考面積は`4w+4h`、円は`4πr`、半径rの角丸長方形は`4w+4h−(16−4π)r`。公式解説の式であり、未フォーカスの部品又はサブ部品の形状と寸法を使う。公式解説が認める2 CSS pxの境界そのものによる経路も確認し、参考式だけから全ての2px境界を不適合にしない。細い線でも離れた位置では面積が増えるため、線幅だけで不適合を決めない。

出力には元画像・指定ファイルのコピーとSHA-256、面積、前後の比を残す。`wcag_judgement`は常にnullで、測定成功から合格を自動生成しない。対象の網羅、例外、表示の識別、操作と測定結果の比較は、実ページの検査として別に記録する。部分的な色だけを測り面積が不足した場合、未測定の領域を調べるまで不適合を確定しない。

## 確認した範囲

[3種類の実表示の校正](https://github.com/k-s-h-r/wcag-audit-kit/blob/adf459777fa43ea0898a95e43edf5dbdde0684b7/validation/focus-appearance/README.md)では、著者指定の4px輪郭、面積が足りない1px輪郭、前後が似た色の4px輪郭を実際のTabで比較した。これは既知の単純な表示の方法確認であり、任意の形状・影・色管理・端末又は全ページに対する精度評価ではない。

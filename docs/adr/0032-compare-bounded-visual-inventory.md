# ADR 0032：画像候補の取得照合を適合判定から分離する

日付：2026-11-18。状態：提案。対象：T007。前提：ADR 0028・0031の提案コード。

## 背景

固定したnative画像7行とタイトル3行がT018で各2回一致した。T003の全体出力には画像候補の取得契約が残るため、ADR 0028の初回選定後、1種類だけを再選定する。

## 決定

初期状態の表示中DOMからCSSのURL背景・SVGルート・canvasを列挙し、対象と形式を照合する。実装前のplan.jsonに3契約、対応範囲、除外を固定した。証拠欠落・部分取得・未対応の契約条件は未確認とする。装飾であるという意味判断は実装せず、decorative条件を持つ契約を候補一致だけで成功にしない。

取得一致・不一致はWCAGの判定と別の結果、帳票の別表とする。完全な取得での不一致は厳格採点を失敗にする。未対応は残作業に保持する。新しい実装・採点器の版で新規runを作り、過去runを更新しない。

## 代替案と影響

全17観点の接続や画像の意味推定は範囲を広げるため採用しない。候補一致を1.1.1適合へ変換する案も採用しない。フレーム・閉じたShadow DOM・静穏待ちの上限がある場合は完全取得とは扱わない。疑似要素、グラデーション、将来の全状態は対象外。

## 検証

欠落、余分な対象、形式違い、証拠改変、部分取得、未対応の装飾条件を試験する。新規の画像・タイトル収集で固定10行を維持し、JSON・HTML・Excelを読み戻す。過去記録のチェックサムを確認する。

なお過去の説明文のstrict終了値に誤記があった。原始証拠は変更せず、T002/RESULTS.mdとT018/RESULTS.mdで訂正する。タイトルは選択チェック完了で0、画像は未確認があり2。どちらも全体の適合確認は未完了である。

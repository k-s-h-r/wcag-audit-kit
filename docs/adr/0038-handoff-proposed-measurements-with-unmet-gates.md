# ADR 0038：提案成果と未達の合流条件を分けて引き継ぐ

日付：2026-11-18。状態：提案。対象：wcag-devによる継続とT011・T014の再開条件。

## 背景

約50タスクを上限とする継続依頼で、14タスクの測定・修正・調査を進めた。限定した機械検査とページ別出力は実証できたが、ホスト起動・正解の隔離・実SRの互換性が残り、実AIと統合受入の開始条件は揃わない。成果は依存PRで提案中で、main採用前である。

## 決定

タスクの完了根拠・PR・未確認・次の具体的な操作を担当文書へ揃え、開発計画から合流条件を参照する。既存の待ちを複製せず、実証していない能力は未達に残す。50件を目標件数とは扱わない。今回マージは依頼されていないため実施しない。

## 代替案と影響

ホストの起動失敗をスキル成功にする案、正常対照のない無発話を不適合にする案、基準値の成績だけで全AAを完了扱いする案は採用しない。正解を読んだ開発セッションのAI判断でT011を代替しない。T007の未対応の装飾条件も未確認に保持する。

依存PRの連鎖と独立したT012のPRを明記する。新規の最終進捗台帳は増やさず、既存ROADMAPと担当タスクを更新する。この調整PRはT013とT012の提案を統合した確認用headを持ち、両PRの採用を前提とする。

## 検証

実行可能な単体試験・同期・生成物検査、保存済みのmainと開発測定のチェックサム、依存関係と参照先を確認する。実施した検査の範囲と未実施の実AI・統合受入を区別する。レビュー指摘の訂正は原始証拠の変更でなく、新しい方法・run・RESULTS.mdから追跡する。

既存ADR 0004の`references/checksheet.md`は過去の配置を指すリンクで、mainと同じまま保持した。現在の[チェックシート仕様](../../skills/wcag-audit-kit/references/checksheet.md)を参照する。現在の文書のリンク不足と、履歴中の旧配置への参照を区別する。

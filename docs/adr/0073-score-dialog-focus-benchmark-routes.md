# 0073 ダイアログを閉じる実入力と次のTabを採点する

日付：2026-11-20 / 状態：Proposed

## 背景

[ADR 0072](0072-observe-focus-after-dialog-button.md)の機械検査は、閉じるボタンの実入力でモーダルが消えたときに、閉じた直後と次のTabでのフォーカスを記録する。この証拠を問題集でも対象と経路に対応付け、検出と正常例の区別を回帰試験できるようにする。

## 決定

- 2.4.3-02に単一ダイアログの問題例と正常例を追加する。各ページでクリック・Enter・Spaceを個別に採点する。既存ケースの期待結果は維持する。
- 開き元、ダイアログ、閉じるボタン、入力を公開の操作条件に置く。採点器は、完了した実行の探索記録と入力イベント、モーダルの前後および次のTabを照合する。期待する判定は採点用の正解に置く。
- 開き元への復帰と、文書へ戻って次のTabで開き元より前へ移動した証拠を区別する。実入力と同じ文書を確認できない場合や、次のTabで実際のフォーカス先が確認できない場合は確定しない。

## 代替案と影響

帳票の「通過」「問題あり」だけを読むと、実際の操作と対象を別ケースの証拠から誤って採点できる。探索・入力・前後の状態を同じ試行に結び付け、証拠の出所を帳票へ出す。入れ子、別文書、別の要素へフォーカスする業務フローは追加確認。問題集の版が変わるため、過去との比較では既存の観点と新規の観点を区別する。

## 検証方法

2.4.3のChromium収集を行い、問題例と正常例の3入力に対応する採点を確認する。同じ証拠で接続前の採点も実行する。単体試験では、経路・対象・文書・イベント順序が一致しない記録、未保存の証拠、フォーカス先の不明な記録を確定しないことを確認する。[問題集の操作と再実行手順](../../benchmarks/cases/2.4.3/README.md#ボタンで閉じた直後と次のtab)

# 0064 独立したカードを表候補から絞り込む

日付：2026-11-19 / 状態：Accepted

## 背景

「種類」「受付状況」のような文字を並べる画面では、カードに個別の枠を設けても、列や行がそろうと表候補になる。情報のまとまりをブラウザー側でも確認できる例を使って絞り込みを試す。[Issue #29](https://github.com/k-s-h-r/wcag-audit-kit/issues/29) [ADR 0062](0062-compare-visual-structure-with-browser-roles.md)

## 決定

後続の各行がブラウザーに `article` として認識され、丸い四隅、実線の枠、行間の余白があるまとまりを、単純な表の候補から外す。表・グリッドとして定義されたまとまりや、複数の候補からブラウザーが表・グリッドの役割を認識したまとまりは、表の役割の照合に進める。

## 代替案と影響

枠と位置だけでカードを除くと、同じ装飾のデータ表も除かれる。独立した記事の手掛かりと配置を照合し、役割が不明な例を候補に残す。候補の有無は1.3.1の適否に使わない。

## 検証方法

`python3 tests/visual_structure_probe_browser.py --out <新しい出力先>`。表示画素が一致する、独立した記事のカードと、役割を指定していない列配置の対照を比較する。既存のHTML・ARIAの表と役割が不足する表も再検査する。

# 0075 メニューのフォーカス、Tab前後のURL、文中リンクの寸法を照合する

日付：2026-11-20 / 状態：Proposed

## 背景

[ADR 0074](0074-score-bounded-browser-measurements.md)の実行では、問題と正常例の機械判定87観点が一致した。7件では、問題集で指定した操作前後の状態や寸法を記録できたかの照合が残った。内訳はメニューの実キーとフォーカス移動4件、Tab前後のURL2件、文中リンクの寸法1件である。

## 決定

- メニューでは、公開手順で指定した対象の表示・展開状態を各キーの前後に記録する。キーが届く文書、操作順、フォーカスとURL、対象の状態を確認する。最初の指定対象へ到達する前のTabも実行記録に残す。
- URLは、実Tabで指定対象がフォーカスを受けた記録と、操作前後の文書およびURLを照合する。文中リンクは、実際の矩形と同じ行の前後に文章があることを照合する。
- [ADR 0074](0074-score-bounded-browser-measurements.md)の凍結済み記録を使い、取得した記録が指定条件と一致したかを帳票に出す。`--residual-only` の実行でもこの3種類を照合する。

## 代替案と影響

通常の判定が一致したことから、必要な記録が取れたとは判断できない。個々の記録を照合し、正しいキーとその結果の記録がそろえば、フォーカスが意図しない場所へ飛ぶ問題例でも取得は一致する。証拠が欠ける場合やキーが別の文書へ届いた場合は未確認にする。既存の期待結果は維持する。

## 検証方法

Chromiumで2.1.2、2.4.3、3.2.1、2.5.8の機械モードと、公開操作条件を絞った実行をそれぞれ確認する。操作前後のフォーカス・展開状態、URL、文中リンクの矩形が保存され、HTML・Excelの記録欄から証拠を追えることを確認する。単体試験では、対象の欠落、信頼できないキー、同じ文書に関する記録の矛盾、文中リンクの条件不足を未確認にする。

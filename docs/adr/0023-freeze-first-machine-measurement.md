# 0023 最初の機械測定を10行と既存の実行条件へ固定する

日付：2026-11-18 / 状態：Proposed

## 背景

T002・T003を同条件で測るため、T001で母数と除外範囲を先に固定する必要がある。出力がある行だけ集めると、操作後の未出力が成績から消える。

## 決定

既存問題集の2.4.2-01の3行、image-alt対応の1.1.1-01の7行をCSVへ固定する。問題集と検証実装は変更せず、既存machine収集を各基準2回・新規runで使う。除外判定と取得未接続も併記する。分析例は既存の採点出力と固定行を照合し、未出力を未確認へ残す。

## 代替案

新しい観点フィルターやジョブ基盤を先に作る案は、測る前に測定対象を変えるため採用しない。正解を読んだAIによる補完は機械の基準値へ含めない。

## 影響

比較条件と母数が追跡できる。同じOSユーザー内の決定的な機械収集であり、正解を物理的に隔離したAI実験ではない。基準値の固定と検証能力の達成を区別する。

## 検証方法

全選択行と既存正解を照合し、実装・環境の識別値を記録する。判定のない行を含む集計例を確認する。計画のハッシュをT002・T003から参照する。[計画と集計例](../../validation/development/T001/README.md)を参照。

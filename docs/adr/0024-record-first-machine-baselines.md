# 0024 最初の2観点を変更せず2回ずつ測る

日付：2026-11-18 / 状態：Proposed

## 背景

T001で固定した母数に対し、実装改善前の成績と再現性を残す必要がある。コマンドの成功と検証能力の達成は異なる。

## 決定

T002とT003を別worktree・別runで各2回収集し、未出力を含む全固定行を既存の採点で数える。タイトル3行は一致し、画像7行のうち5行が一致、操作後2行は未確認だった。修正はこのPRへ混ぜずT009へ渡す。全体のstrict終了コード2と意味判断・取得未接続を保持する。

## 代替案

見えた結果だけ集めたり、操作後をAIで埋めたりする方法は、機械収集の基準値を隠すため使わない。問題集の期待値も変更しない。

## 影響

正常・異常・未出力を同じ母数で比較できる。開発担当は正解を知っているため、決定的な収集器だけの評価とし、正解を伏せたAI評価とは扱わない。G1は未達であり、この基準値PRの採用だけでは達成しない。

## 検証方法

計画・実装・問題集・環境・予算を実行前に照合する。全4runの原始証拠と実装を保存し、同じ対象の判定が再実行で変わらないことを確認した。[T002](../../validation/development/T002/README.md)と[T003](../../validation/development/T003/README.md)を参照。

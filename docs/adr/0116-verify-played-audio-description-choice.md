# 0116 キーで音声解説を選び、再生した音声と映像を照合する

状態　Proposed

## 背景

T028では、別々のURLで再生した媒体を比べ、選んだ視覚情報が音声解説で伝わるかを調べた。T009では指定した部品をクリックし、スクリプトで再生して資源が切り替わるかを調べた。今回の試験では、実キーで選択して再生し、選んだ解説から申し込みに必要な受付コードを得られるか確かめる。[以前の実測](../../validation/development/T028/README.md) · [T009](../tasks/T009-machine-gap.md)

## 決定

1.2.5問題集のc03とc04を、対応する公開ページからChromiumで操作する。p04を同じ条件で再生し、音声解説を選ばない対照にする。先に固定した条件に従い、TabとEnterで選択し、ネイティブの再生ボタンに戻ってSpaceで再生する。入力、フォーカス、選択状態、HTTP応答、`currentSrc`、再生時刻を記録する。

再生音声の収録とHTTPで配信したファイルを別々にデコードする。受付コードの表示は実画面で確かめ、同じコードが再生音声に含まれるかを認識結果と波形で照合する。既存の `page` と `record` を使い、対応するケースに証拠を付ける。達成基準全体に確認が残る場合は、観察した事実と残る作業を検査票に記す。

## 代替案

押下状態や `src` は選択の表示や指定先を調べる証拠になる。今回の2例は同じ押下状態になり、その後に再生される音声が異なる。配信と再生に対応した記録を使い、視覚情報が音声で伝わるところまで比較する。スピーカー出力を収録する方法もある。今回の試験では、デコードした音声トラックをブラウザーから収録し、音声解説が選択した動画の再生に含まれるかを確認する。

## 影響と検証

新しい観察はT028の別runに置く。2例と未選択の対照で、全区間の再生、配信と収録の一致、受付コードの表示と音声、選択後の検査票を照合する。別環境と受付コード以外の情報は追加の試験で扱う。[条件と再現手順](../../validation/development/T028/description-choice/README.md)

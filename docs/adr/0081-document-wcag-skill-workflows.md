# 0081 WCAGスキルの処理の流れを図解する

- 日付 2026-11-21
- 状態 Proposed

## 背景

[設計方針](../SKILL-DESIGN.md)には監査用4スキルの責務があり、詳しい動作は各 `SKILL.md` と参照資料にある。開発用2スキルの動作は開発タスク側に記載している。利用者が依頼に合うスキルを選び、実行中の処理と受け取る成果物を一か所で確認できるようにする。

## 決定

[WCAGスキルの図解](../WCAG-SKILL-GUIDE.md)をリポジトリに置き、READMEから参照する。6スキルの入力と出力を表で比べ、各スキルでの処理の順序、分岐、受け渡す情報をMermaid図で示す。詳細は各スキルと既存の参照資料にリンクする。

## 代替案

READMEに全手順を書き足す案では、導入手順と動作の説明が同じページで長くなる。設計方針へ追記する案では、利用者向けの流れと設計判断の履歴が混在する。図解を独立させると、利用者が目的で読み始め、必要な設定や手順を元の文書で確かめられる。

## 影響

対象はリポジトリの説明文書。実際の呼び出し、検査、集計は各スキルとCLIの仕様に従う。スキルの開始条件、処理順序、成果物が変わるときは、対応する図と説明も見直す。

## 検証方法

6スキルの記述を `SKILL.md`、検証モード、ページ検査手順と照合する。相対リンクと図の描画を確認し、初期画面だけの依頼、指定一覧の再開、報告だけの依頼、開発タスクの整理で、開始条件と出力を追えるか確かめる。

## 確認結果

6スキルの記述と参照リンク28件を照合した。Mermaidの6図をChromeで幅320・390・1280ピクセルで表示し、文字の重なりがなく、最小の図中文字が12ピクセル以上であることを確認した。スキルの共通リソースは `python3 scripts/sync_skills.py --check` で同期を確認した。実ホストでのスキル呼び出しと監査の実行は、既存の検証記録を参照する。

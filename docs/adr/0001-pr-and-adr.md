# 0001 PRとADRによる変更管理

日付：2026-11-15 / 状態：Proposed

## 背景

利用者から、今後の変更はPRを作り、設計判断をADRへ残すよう指定された。初版の登録後も、この方針を担当者やAIのセッションをまたいで維持する必要がある。

## 決定

変更は作業ブランチで行い、PRから新しいADRへリンクする。mainへの直接pushと、依頼のないマージは行わない。AI向けの指示をAGENTS.md、人向けの手順をCONTRIBUTING.md、レビュー項目をPRテンプレートへ置く。

## 代替案

会話だけに方針を残す方法では、別のセッションや担当者が把握できない。GitHubのブランチ保護だけでは、判断の背景までは記録できない。今回、リポジトリの管理設定は変更しない。

## 影響

小さい変更にも短いADRを付ける。過去の判断を変更する場合は、新しいADRから旧記録を参照する。今回のPRもこの運用に従う。

## 検証方法

作業ブランチをmainから作成し、AGENTS.mdとPRテンプレートの指示、ADRへの相対リンク、実際に作成したPRのbaseとheadを確認する。

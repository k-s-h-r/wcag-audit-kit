# 0082 wcag-page の操作と証拠をHTMLで図解する

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0081](0081-document-wcag-skill-workflows.md)の概要図はスキルの選択と流れを示す。メニューを開いた後のキーの選択、候補表示の判定、操作前後の差分再検査には、それぞれ分岐と観察条件がある。利用者が観察した操作と帳票の結果を対応づけられるよう、詳しい説明を追加する。

## 決定

[wcag-page の動作を追う](../WCAG-PAGE-WORKFLOW.html)を作り、概要からリンクする。対象は `main` の `dc43bfe`。初期収集、操作の再生、キー経路ごとの観察、差分再検査、追加計測、報告を図と例で示す。HTMLには本文と図のスタイルを同梱し、ブラウザーから直接開けるようにする。元のPRや実装へリンクして、例で示した条件を追えるようにする。

## 代替案

概要のMermaid図を大きくすると、スキル間の関係を見たい人と、特定の操作経路を追いたい人が同じ図を読むことになる。手順書へ追記する案では、AIへの指示と、人が挙動を理解するための説明が混在する。概要から詳細へ進める構成にする。

## 影響

変更対象は文書。最新の資料か確かめられるよう、参照した実装のコミットを表示する。図の分岐、探索上限、証拠の配置に関わる変更では解説も更新対象とする。

## 検証方法と結果

- HTMLの9図をChromeで幅320・390・768・1280ピクセルで表示した。目次、本文への移動、詳細の開閉をキーボードで確認した。HTMLに対してaxeのWCAG 2.0 A・AAと2.1 AAのルールで違反は出なかった。
- 新しい一時runで `tests/initial_page_audit_browser.py`、`tests/keyboard_close_browser.py`、`tests/keyboard_combobox_browser.py` を実行し、3件とも通過した。Google Chrome 157を使い、実対象サイトへの監査や実ホストの呼び出し確認は別に扱った。

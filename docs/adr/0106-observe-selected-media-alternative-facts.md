# 0106 実際の再生とデコード音声で媒体の代替を比較する

状態　Proposed

## 背景

既存の媒体試験では字幕の実表示を取得し、既知の合成音声でWhisper.cppを校正した。校正では認識語の誤りや無音の誤出力があり、字幕との一致は判断保留のまま残した。発話、字幕、書き起こし、音声解説の比較を、固定した事実で実測する必要がある。[既存の媒体試験](../../validation/media/README.md)

## 決定

ローカルの3 URLで同じ7秒動画を再生する。実際に配信された媒体のハッシュ、デコードした音声の認識結果、操作ログ、指定時刻での字幕と画像を対応させる。原本の映像で確認できる「Saved」を選び、同じ事実を伝える場合と省く場合の書き起こしを比較する。音声解説は同じ映像の2例を再生し、デコードした音声の波形と認識結果を照合する。

試験する事実、時刻、比較条件を実行前に固定する。原始証拠は新しいrunに置く。未確認の範囲を保持し、新しい比較結果から達成基準全体の適合を出さない。

## 代替案

字幕ファイルと生成時の台本だけの比較では、実際に表示された字幕やデコードされた音声を確認できない。全文の音声認識だけでは、発話の境界や非言語音を確認できない。指定した時刻の実画面と、音声の認識と波形をそれぞれ保存し、判定を対応する事実に限る。

## 影響と検証

既存の媒体スキルと判定を維持する。比較の実装と結果はT028に置き、選んだ事実と元の映像・音声を第三者が照合できるようにする。固有名詞、複数話者、非言語音、全区間の意味と同期は個別に検査する。[タスク](../tasks/T028-observe-media-alternatives.md) · [実測と再現手順](../../validation/development/T028/README.md)

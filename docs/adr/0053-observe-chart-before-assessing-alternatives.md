# 0053 図の情報を読み取ってから代替説明と比べる

日付：2026-11-19 / 状態：Accepted

## 背景

正解を隔離して、保存済みのページ証拠から図の代替説明とタイトルの意味を判断する4件を試した。初回は画像を2件とも処理できたが、図の情報を説明できないまま検査が終わった。タイトル2件にも有効な判定はなかった。[T011](../tasks/T011-ai-residual-review.md)

## 決定

図の比較は、図に描かれた情報の取得と、取得した情報を代替説明と比べる段階を分けて測る。保存画像の対象矩形を保存済みDOMから求め、元画像の画素を原寸で切り出す。読み取りの入力には画像だけを使い、図の文字や値を読み取れたことを確かめてから代替説明とページの目的を渡す。画素が同じことをハッシュで確認できる場合は、図を読んだ観察だけを共用する。代替説明の判断には、そのページで得た両方の情報と対応を示す。

## 代替案と影響

全画面を渡す方法では、対象の周辺も一度に確認できる。図の文字が判定に必要な場合は、原寸の対象部分を確認することで、画像を見て取得した情報と、代替説明から得た情報を照合できる。対象外の文脈は元の画像と本文を参照する。元画像と切り出し位置、両方のハッシュ、読み取った情報を証拠として追跡する。

## 検証方法

1.1.1-04の開いた2状態で、図だけを渡す読み取りと、各ページでの代替説明の比較を別セッションで行う。画像の処理ログと取得値を照合し、読み取りを共有する場合は両方の画像ハッシュを確認する。判定の予測は元の状態の証拠とともにベンチマークへ取り込み、比較を具体的に説明できたかも確認する。正常例と問題例の結果、時間、トークン数は[T011](../tasks/T011-ai-residual-review.md)に記録する。

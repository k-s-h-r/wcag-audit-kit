# 0083 ベンチマークの対照例をHTMLで比較する

- 日付 2026-11-21
- 状態 Proposed

## 背景

ベンチマークには、ARIAを使わない数量変更の対照や、同じ図表で代替文の有無を変えた対照がある。既存の基準別資料から各ページを開ける。操作や見た目を比較するには、試験ページを個別に探して表示する必要があった。

## 決定

[試験ページのHTML見本帳](../../benchmarks/PATTERN-GALLERY.html)で、既存の代表5組をそのまま読み込み、正常例と問題例を並べる。採点側の一覧には、既存の達成基準と追加パターンから試験ページを探せる検索を用意する。閃光の試験は、同梱の時系列資料にリンクする。

一覧データは既存の問題集索引と同じ入力から生成し、HTMLに埋め込む。これにより、試験ページへの相対パスを保ったまま手元のブラウザーで開ける。問題集を更新したら、従来の `benchmarks/build_fixture_index.py` で一覧データも更新する。

## 代替案

代表例をHTMLへ書き直す案では、実際に採点に使うページとの違いを追う必要がある。既存ページを読み込めば、見た目や操作を同じ入力で比べられる。実行時に索引JSONを取得する案はHTTPでの配信が必要になるため、手元のブラウザーで開けるようにデータを埋め込む。

## 影響

見本帳は採点側の資料に置く。ブラインド検査担当には従来どおり `public/` のページと必要な操作手順を渡す。対照の説明は作成者が定めた観点の期待結果を扱う。一般サイトでの検出率は、別の評価で調べる。

## 検証方法と結果

- `python3 benchmarks/build_fixture_index.py --check` で埋め込んだ一覧を照合した。86基準・306ケース・314ページ分の参照と、61組の追加パターンを確認した。ベンチマークのユニット試験は62件中57件が通過し、5件は実行条件によりスキップされた。
- Chromeで代表5組を試し、数量の変更、Tabでの到達、追加された画像と代替文、表の列見出し、候補表示と展開状態を確認した。幅320・390・768・1280pxで検索・表示を確認し、見本帳本体では対象のaxeルールで違反が出なかった。

# 0131 URL起点のベンチマークで採点範囲と検出率を示す

状態はProposed。

## 背景

URLだけを渡すベンチマークは、問題集のうち機械判定の対象として登録された76ページ・87行を採点する。従来のHTMLには採点外のページや観点が出ず、1.1.1の11ページのうち4ページだけが表示される理由を確認できなかった。全体の集計でも、問題側の未確定と問題なし・該当なしを期待する側の未確定を区別できなかった。[ADR 0130](0130-report-url-only-benchmark-regressions.md) · [T044](../tasks/T044-compare-url-only-benchmark-results.md)

## 決定

既知の問題の検出率、全採点行の正解率、確定判定が出た割合と、それぞれの分子・分母をHTMLの先頭に出す。期待結果ごとに、正解、誤判定、観察後の判定保留、状態・経路の未確認、収集失敗を数える。正解と対応付かなかった指摘は証拠へのリンクを付ける。

ページ別の採点範囲は、採点結果と同じダイジェストの問題集を参照できた場合に表示する。問題集のファイルや正解が変わっている場合は、保存された採点行と、その外側を確認できない理由を表示する。

## 代替案と影響

HTMLの結果ラベルだけを言い換える案では、未確定が既知の問題の何件を占めるかや、採点外のページの理由が残る。採点対象を全ページに広げる案では、意味の照合と証拠取得を含めた別の測定になる。今回の変更範囲はHTMLの表示とし、既存の採点JSONや前回比較を利用する。

## 検証方法

76ページの保存済み収集からHTMLを作り、採点JSONの一致、既存JSONとの比較、1.1.1の11ページの範囲と7行の結果を確認する。PC幅とスマホ相当幅で内訳と証拠へのリンクを確認する。問題集の版が違うケースでは採点外のページを推測せず、採点行を表示できることを試験する。

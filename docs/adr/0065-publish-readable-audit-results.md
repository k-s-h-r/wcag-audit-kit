# 0065 ページ検査の結果を修正担当者が使える形で出力する

日付：2026-11-20 / 状態：Proposed

## 背景

単独ページ検査では、収集直後の全体HTMLと追加判定後のページ別HTMLが同じフォルダーに並び、同じページでも内容が異なった。HTMLの先頭にはモードごとの仕様表があり、基準の一般的な確認観点と検査票数が結果欄に表示された。設定済みの状態を `page` で収集すると、保存されたaxeの結果が帳票に集計されなかった。[ADR 0004](0004-human-checksheet.md)の閲覧用帳票を、実際に観察した事実から修正箇所を調べられる形へ更新する。

## 決定

- HTMLは修正箇所、実施結果、残る確認の順に読む。基準の適用対象が証拠で確認できた場合は、基準全体の判定が未確定でも「適用あり」と表示する。
- 結果は保存した観察と機械ルールから作る。対象なしはルール単位で表示する。一般的な確認観点と検査モードの仕様は詳細で参照できる。
- 設定済みの収集と自動探索の両方で、保存したaxeの結果を帳票に反映する。対象ごとの指摘は要素と状態から証拠を追える。機械検査を基準全体の判定に流用しない。
- 新しい検査の閲覧用出力は `reports/`、処理用データは `data/`、検査中の台帳と定義は `work/`、元の収集ログと証拠は `work/evidence/` に置く。単独ページの閲覧用HTMLとExcelを再出力するときは同じパスを更新する。複数ページの個別帳票はページごとのフォルダーへ置く。

## 代替案と影響

従来の配置のままHTMLだけ短くする案では、収集時点の版とページ別の版が混在する。新旧の場所に同じファイルを出す案では、どれが最新版かをファイル名から判断できない。新規runは用途ごとの配置にし、従来のrunは既存の場所から参照できる。証拠パスは台帳内で従来どおり相対指定し、HTML・ExcelのリンクとJSONの `evidence_base` に参照先を反映する。明示的に出力先を指定する共同作業用Excelは、従来どおり新しいファイルを作る。

## 検証方法

旧形式の保存結果を読み戻し、元の判定・定義・証拠のハッシュが変わらないことを確認する。初期表示と設定済み状態を収集した新しいrunで、HTML・JSON・Excelへの反映、適用と判定の表示、1ページの再出力、複数ページからの絞り込みを確認する。幅320pxと1280pxのChromeで表示、証拠リンク、レポート自体のaxe結果を検証する。

# 0027 実測した文字コントラストを対象と状態ごとに採点する

日付：2026-11-19 / 状態：Accepted

## 背景

1.4.3の問題集では、実際のページ検査でaxeの文字コントラスト証拠を取得しても採点に使っていなかった。ボタン操作で有効化する例は、採点側の状態と実行時の観察条件も対応していなかった。

## 決定

`color-contrast`の採点への取り込みは1.4.3-01に限定し、宣言した状態と実際に測定した要素が一致する場合に使う。axeの判定と、実測値、比較に使った基準値（4.5:1または3:1）、前景色・背景色・文字サイズ・太さを記録する。表示用の丸められた比から判定を計算し直すと境界値で判定が変わり得るため、axeの判定を保存する。証拠が不足する対象は判断を保留する。

操作後の有効状態を確認する2ケースでは、ボタンを押して、対象が一つだけ表示され有効になったことを確認する。実行条件を変更したため、問題集1.4.3の版を3から4に上げる。過去の実行記録は保持し、再検査は新しい保存先で行う。

## 検証

```sh
python3 benchmarks/run.py collect --mode machine --criterion 1.4.3 --out <新しい出力先>
python3 benchmarks/run.py score --run <同じ出力先>
```

Chromiumで既存7例を実行した。従来は7例が未採点だった。変更後は、初期と有効化後のそれぞれで2.32:1を問題、18.88:1を通過と判定し、4例が期待結果と一致した。別の測定手順を使う2例と、無効コントロールの除外を確認する1例は未採点に残った。別の試験では4.47:1の同じ配色が通常文字で問題、大きな太字で通過となり、グラデーションで測定が不確かな例は保留となった。

既存の1.1.1と2.4.2の機械検査10行も期待結果と一致した。文字コントラストの結果は測定対象と状態ごとの確認結果であり、ページ全体の1.4.3の判定には追加検査が必要。

# 0028 取得照合の範囲を選び、保存済み帳票を読み取りで比較する

日付：2026-11-18 / 状態：Proposed

## 背景

T007では基準値で必要になった取得を選び、T008では機械結果と残作業の報告を照合する。未確認を数える形式だけ整えて実際の取得不足を隠してはならない。

## 決定

T001のnative imgとタイトルの10行には、現行のCSS背景・SVG・canvas等の列挙契約を必須として混ぜない。画像の不足は操作の除外と初期だけの採点に分けてT009へ渡す。今回は適した接続対象がなく、取得の選定調査を記録して実装は保留する。全取得未接続は未確認として保持する。

既存4runのJSON・HTML・Excelと28ページ報告を読み取りで比較する。不一致がなかったため報告コードは変更しない。

## 代替案

列挙できたことを画像の適合へ変換する案や、見た目だけの帳票変更を加える案は採用しない。固定の55票を前提にせず、実際の状態と票数を使う。

## 影響

G1の限定した範囲と、残る取得・意味判断を分けて追える。取得の実装は別の測定範囲で再開する。旧runと判定は変わらない。

## 検証方法

4runのHTMLとExcelを読戻し、原データ4,676ファイルの前後のハッシュ不変を確認した。[T007](../../validation/development/T007/README.md)・[T008](../../validation/development/T008/README.md)を参照。

# 0027 URL一覧化を有限の既知サイトで先に測る

日付：2026-11-18 / 状態：Proposed

## 背景

T006では指定一覧とリンク収集の既存能力を測り、URL候補と試験対象を区別する必要がある。

## 決定

相対URL・重複・クエリー・ハッシュ・範囲外・404・上限・操作後だけのリンクを含む専用fixtureを使う。収集器を変更せず、期待集合と範囲を先に固定する。指定6URL、収集9候補、上限2で未訪問7件を記録した。

## 代替案

新しいサイトマップ・動的巡回を基準値へ混ぜる案は採用しない。visitedを成功や全体網羅にする案も採用しない。

## 影響

T010へ指定一覧を、T013へ候補と限界を渡せる。操作後リンクは未発見で、個別の除外理由も現出力にない。必要な改善は別作業で扱う。

## 検証方法

configuredでHTTPリクエスト0、discoverで期待URL集合と404、上限による未訪問、クエリー・ハッシュの保持を実測した。[T006](../../validation/development/T006/README.md)を参照。

# 0055 タイトルが説明する主題と目的を別々に確認する

日付：2026-11-19 / 状態：Accepted

## 背景

ローカルモデルは、タイトルが主題を説明していると述べながら、不適合とした。達成基準2.4.2は、題名がページの主題又は目的を説明することを求めている。[基準本文](../../skills/wcag-audit-kit/references/sources/2.4.2.md) [T011](../tasks/T011-ai-residual-review.md)

## 決定

保存済みの題名と本文を根拠に、題名がページの主題を説明するか、目的を説明するかを別々に確認する。少なくとも一方の説明を確認できた場合は、この観点の要件を満たす。両方を説明していないことを確認できた場合は不適合とし、十分な根拠がない場合は判断を保留する。題名の存在など他の観点は対応する票で確認する。

## 代替案と影響

モデルに適否だけを求めると、基準の読み違いと、それぞれの主題や目的についての観察の誤りを追いにくい。実測では観察を別々に返し、条件をコードで適用して採点した。既存の観点の要件を明示したもので、機械検査に新しい題名の適否判定は追加しない。

## 検証方法

正解を隔離したT011の正常例c02と問題例c03で、同じページの題名と本文を実モデルへ渡す。出力された題名と本文の引用を保存済み証拠に照合した後、二つの観察に条件を適用する。両方の結果を公式の採点CLIで確認する。T014では別のページに適用する。

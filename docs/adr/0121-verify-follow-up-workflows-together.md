# 0121 追加した検査を同じ配布版で確認する

状態：Proposed

## 背景

[ADR 0108](0108-run-vision-acceptance-on-an-integrated-revision.md)の初回統合後に、ダイアログの離脱、検査票の操作証拠、文書移動、参照先の再検査、隣り合うボタンの寸法と間隔を個別に確かめた。いくつかの変更は同じ探索と採点の入口に触れるため、組み合わせた版を同じ手順で検証する。

## 決定

実測済みのT030ブランチを起点に、検査を実行するコード、検査手順、関係するテストを一つの作業ブランチに置く。探索の実装識別子に、組み合わせた入力観察と寸法・間隔の両方を含める。採点では離脱と間隔をそれぞれの観点から原始証拠へ照合する。

## 代替案と影響

個別ブランチの試験だけでは、共通のファイルを合わせた後の探索順や帳票の出力を確認できない。組み合わせた版で既存の76ページを試すとともに、機械採点の行がない証拠の受け渡しは代表対照を別runで試す。

## 検証

URLだけの問題集、検査票への証拠の表示、遮断した文書移動、ARIA参照の再検査を確認する。配布スキルを同期し、個別の原始証拠と組み合わせ後の記録を追える形にする。[実装・試験条件](../../validation/development/vision-follow-up/README.md)

# 0074 公開の操作条件でブラウザー計測を採点する

日付：2026-11-20 / 状態：Proposed

## 背景

[ADR 0071](0071-track-benchmark-machine-detection-targets.md)で機械検出対象を追跡し、[ADR 0073](0073-score-dialog-focus-benchmark-routes.md)で単一ダイアログの実入力とフォーカスを照合した。未確認の問題28件と対照30件には、DOMの存在確認だけでは分からない操作、タイマー、メディアの状態が含まれる。

## 決定

- 問題集の公開状態に対象と操作・計測条件を置く。既存の期待結果は維持し、採点側に保持する。
- Chromiumの実入力、DOM・アクセシビリティツリー、再生状態、画素、ブラウザー時計の証拠を観点に応じて収集する。証拠は実行、ページ、公開資料のハッシュ、状態と結び付けて凍結する。範囲外への通信と、文書や証拠を確認できない経路は保留する。
- 通常のベンチマークから計測を追加する。追加した計測だけの回帰は `--residual-only` で別に実行できる。出力の採点範囲を表示し、通常実行との比較を分ける。

## 代替案と影響

HTMLの文字列、ケース番号、表示名だけから正解を推定すると、操作しても同じ状態に留まる問題を見落とす。公開の操作条件は両対照に共通の観測を与え、実行後の状態で区別する。文字や音声の意味、仮想時計の外の保存期限、未観測の操作経路、自由な形状の輪郭は別の確認が残る。新しい計測は有限の問題集での回帰に使う。

## 検証方法

公開の操作条件だけを使うChromium実行で、問題・正常対照の両方を確認する。通常の機械モードで既存観点を再確認し、HTML・Excelと凍結済み証拠が対応することを確認する。単体試験では、範囲外の通信、未確認の入力、別の証拠を使った場合の扱いを確認する。

# 0089 検査の例と指摘をWCAGの達成基準につなぐ

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0088](0088-center-the-vision-on-conformance.md)でメモの冒頭にWCAG適合の結論と成果物を置いた。検査の例と未対応箇所の説明にも、達成基準とのつながりが必要だった。

## 決定

[やりたいことメモ](../VISION.md)で、カレンダーを調べる例を「1.4.1 色の使用」の判定につなげる。未対応箇所の一覧から、満たしていない達成基準も分かるように書く。

## 代替案

すべての例に基準番号を添える案も考えた。メモでは代表例を一つ示し、個々の判定条件は基準ごとの検査定義に置く。

## 影響

観察したことがWCAGの判定と二つの成果物にどうつながるかを、メモの中で追える。

## 検証方法

カレンダーの例を[1.4.1の検査定義](../../skills/wcag-audit-kit/references/criteria/1.4.1.md)と照合し、両方の成果物から達成基準をたどれる記述か確認する。

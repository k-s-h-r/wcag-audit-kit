# 0043 使用するOrcaの版に合わせて起動引数を選ぶ

日付：2026-11-19 / 状態：Accepted

## 背景

Orca 51.1では設定ディレクトリーや音声・点字を指定していた旧引数が廃止されている。旧引数を渡すと、実際のページ検査へ進めない。版ごとの発話の違いを比較するには、同じCLIで配布バイナリーを起動できる必要がある。

## 決定

指定されたOrcaの `--help` で利用可能な起動引数を確認し、共通のデバッグ出力に加え、その版が受け付ける設定・音声・点字の指定を使う。コンパイル済みのOrca用GSettingsスキーマを含む別のパッケージルートでは、専用のD-Busを起動する段階からそのデータとスキーマを設定する。証拠の収集、利用者の設定と実行中のOrcaを維持する取り決めは従来どおり扱う。

## 代替案と影響

版番号だけで引数を固定すると、配布元のバックポートやパッケージの違いを扱いにくい。実際の起動引数を見て選び、デバッグ出力を取得できる構成で観察を続ける。必要な依存パッケージは利用者が指定する環境に用意する。

## 検証方法

`python3 -m unittest discover -s tests -p 'test_native_orca_runtime.py'`。旧引数の維持、廃止済み引数の除外、既存プロセスを置き換える引数の省略を確認する。展開したOrca 51.1とChromium 156で、配布バイナリーをそのまま起動し、保存ボタンと通知の発話を取得した。

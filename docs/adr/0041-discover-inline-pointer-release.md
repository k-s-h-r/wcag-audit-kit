# 0041 ポインターを離したときに反応する要素を探索する

日付：2026-11-19 / 状態：Accepted

## 背景

クリックの見た目を持つ段落や汎用要素は、ネイティブ部品やARIAの役割を持たないことがある。Chromiumの再現ページでは、`addEventListener('pointerup', ...)` を使う要素は見つかったが、同じイベントを `onpointerup` に持つ要素は探索対象に入らなかった。その結果、操作で現れる部品や画像を調べられなかった。

## 決定

表示中の操作候補を探す際、`onpointerup` を既存のイベントプロパティの確認対象に含める。見つかった要素には従来の探索制約を適用し、マウス入力を試す。発見やマウス操作の成功から、キーボードで使えるかやWCAGの適否を判定しない。

## 代替案と影響

すべての汎用要素を押すと、操作範囲と副作用を制限しにくい。今回は再現できたイベントに範囲を絞る。保存・送信などの探索制限は従来どおりとし、イベント委譲や画面外の状態に対する網羅性は別に確認する。

## 検証方法

`python3 tests/pointer_release_controls_browser.py --out <新しい保存先>` を実行する。初期表示の操作候補、実ポインターによるパネルの展開、その中の部品を押した後の画像とaxeの結果をChromiumで照合する。従来から取得できるイベント登録も同じページで確認する。取得できた操作経路と、達成基準の判定を分ける。

修正前は要素が候補に現れず、修正後は内側の部品まで到達し、altのない画像を1件検出した。JSON・HTML・Excelから同じ対象と証拠を確認した。最初の要素へのTab到達は確認できず、Enter・Spaceは未到達の記録を残した。

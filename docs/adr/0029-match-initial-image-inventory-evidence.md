# 0029 初期表示の画像要素一覧を取得期待に照合する

日付：2026-11-19 / 状態：Accepted

## 背景

1.1.1の機械検査で、CSS背景画像・インラインSVG・canvasの要素一覧をブラウザーから取得していた。問題集の初期表示2例では、必要な対象が一覧にそろっても取得の結果が未確認になっていた。

## 決定

1.1.1-02の要素一覧のうち、初期表示で対象と形式の対応が指定された取得期待だけを照合する。同じ実行、ページ、URL、環境の取得で、操作前の状態と取得完了を確認する。初期表示の受領記録、マニフェスト、操作記録、要素一覧のハッシュを照合し、途中で打ち切られていない一覧を使う。対象を一つに絞れ、要素が矩形を持ち、計算済みスタイル上で表示され、CSS背景のURLやSVG・canvasの名前空間が指定に対応するときは取得一致を記録する。

結果はJSON・HTML・Excelの取得欄に記録し、達成基準の判定件数と区別する。同じ採点方法で比較した場合は、一致した取得が未確認に戻る変化も回帰として扱う。

## 代替案と影響

タグ名や対象の一部だけで取得成功にすると、別の状態、見つかっていない対象、SVGと同名のHTML要素を誤って数える。保存された証拠に必要な項目がない場合は未確認に残す。画像の用途、代替説明の意味、装飾の確認は別に行う。

既存runの証拠は保持する。名前空間を収録していない旧runからは、この方法で取得を確定できない。再検査は新しい保存先で行う。

## 検証方法

```sh
python3 benchmarks/run.py collect --mode machine --criterion 1.1.1 --criterion 2.4.2 --out <新しい出力先>
python3 benchmarks/run.py score --run <同じ出力先> --strict
python3 tests/benchmark_report_browser.py --report <出力された帳票ディレクトリー> --out <新しい確認先>
```

Chromiumで比較し、取得未確認3件のうち2件が一致した。装飾の意味を確認する1件は未確認。画像・タイトルの判定件数は一致10件、モードによる省略8件、未確認7件で従来と同じだった。厳格採点は終了コード2で未完了を示した。HTMLの幅320pxと1280pxで証拠リンクを開き、Excelをファイルから読み戻して一致を確認した。

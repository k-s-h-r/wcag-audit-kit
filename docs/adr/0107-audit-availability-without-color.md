# 0107 予約カレンダーで選択前の空き状況を確かめる

- 日付 2026-11-21
- 状態 Proposed

## 背景

機械検査だけでは、予約カレンダーの日付の色が何を伝え、日付ごとに別の手がかりがあるか判断できるか分からない。VISIONの例を使い、起点URLから画面を見て操作した結果を1.4.1の検査票へつなげる。 [VISION](../VISION.md#機械とaiに任せたいこと) · [T029](../tasks/T029-audit-availability-without-color.md)

## 決定

同じ日付・予約可否・色・ボタン操作を持つ二つのカレンダーをローカルに用意する。一方は日付ボタンに空き状況の文字を表示する。もう一方は凡例とボタンの色を対応付けると空き状況が分かる。試験前に対照と採点条件を固定し、独立した検査担当には起点URLと評価範囲を渡す。

機械検査を先に保存する。独立した検査担当が選択前の表示と、空きのある日、満席の日を選んだ後の結果を確かめる。画面・操作・判断の記録を、同じURL・初期状態・画面幅で別途収集した `ai` モードの検査票に添付し、既存の報告処理を使う。

## 代替案

二つの色のコントラストだけを測ると、日付ごとの文字や形が何を伝えるかが残る。画面を見て各日を比較し、操作前の手がかりと操作後の結果を両方観察する。

## 影響と検証

測定対象は一週間分の選択前の空き状況。機械検査と追加観察を同じ採点項目で比べ、検査票・不適合箇所・証拠を照合する。 [実証と再実行](../../validation/development/T029/README.md)

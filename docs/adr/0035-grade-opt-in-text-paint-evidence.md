# 0035 明示した文字の測定証拠を問題集の採点に使う

日付：2026-11-19 / 状態：Accepted

## 背景

独立したChromium検査では、1.4.3の静的な対照例の前景・背景の画素を取得できた。測定対象、初期表示、画像、表示条件を照合した場合に、問題集で再現性を追えるようにする。[ADR 0032](0032-verify-visual-evidence-in-isolation.md)

## 決定

採点に使う対象は、問題集の公開作業票で初期表示のセレクターを一つ指定した例に限る。`collect --text-paint`を明示し、`ai`または`full`で選んだ場合に、通常の画像上限とは別の7枚の測定を行う。通常の機械モードとSR併用モードではこの測定を行わない。色を変える処理は隔離した表示中のHTMLに限る。

保存済みのHTMLと測定画像のハッシュ、指定セレクター、状態、実行、表示条件が一致する証拠から比と閾値を照合する。複雑な描画、文字の大きさを確定できない設定、不足した証拠は保留し、確定できる比を丸めずに基準値と比較する。問題集の1.4.3-02の該当行に限り結果を使う。

保存通知の対照は、展開済みのLinux環境と独立したXvfbで任意に再確認する。ブラウザーの表示と役割に加え、実Orcaの合成指示を操作の時点ごとに照合する。音声を録音せず、1組の環境の対照結果を採点へ取り込まない。

## 代替案と影響

結果の数値だけを採点に渡すと、別の対象や表示条件で得た数値を誤って使う。測定時の画像と収集済みの証拠を照合する。七つの表示の切り替えは独立した実行に限定し、通常のページ検査では行わない。無効コントロールの例外やページ全体の適合は確認範囲に含めない。

## 検証方法

```sh
python3 benchmarks/run.py collect --mode ai --criterion 1.4.3 --text-paint --out <新しい保存先>
python3 benchmarks/run.py score --strict --run <同じ保存先>
python3 tests/text_paint_probe_browser.py --out <別の新しい保存先>
```

画像の採点を指定した実行と、指定しない実行を比較する。通常の機械モードの結果と、保存済みrunが読み出せることも確認する。

保存通知は`python3 tests/native_orca_status_browser.py --root <展開済み環境> --out <新しい保存先>`で再現する。Chromium 156・Orca 48.1のp04で保存完了の発話ログがあり、同じ操作をしたp03はキーエコーのみだった。

既存7例の比較で、指定なしは一致4件・未確認3件、画像測定を指定したAI併用モードは一致6件・未確認1件だった。追加2例は通常文字の2.323:1と18.883:1で、比較基準は4.5:1。無効なコントロールの例外は未確認。機械モードは一致4件・未確認3件のままで、画像を保存しなかった。

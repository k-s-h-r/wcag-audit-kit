# 0067 初期状態の証拠画像をページ全体で保存する

日付：2026-11-20 / 状態：Proposed

## 背景

[ADR 0066](0066-choose-page-audit-evidence.md)では、初期状態の画像を操作前の表示領域に限っていた。PC幅とスマホ相当の幅で検査結果を見比べるときに、画面の下に続く内容も初期状態の画像から参照できるようにする。

## 決定

標準の画像を保存する設定では、HTMLの初期状態を、設定した表示幅のままページ全体で撮る。`initial` は環境ごとに全体画像を1枚保存する。`states` と `all` も初期状態は同じ方式で撮る。操作前後の画像は、その時点の表示範囲を保存する。実ブラウザーの拡大、SVG・XML文書は既存の表示領域による撮影方式を使う。標準画像を取得するChromiumではソフトウェア合成を使い、GPUのテクスチャ上限で縦長のページの末尾が欠けるのを防ぐ。

## 代替案と影響

初期状態を何枚かに分けて保存すると、ページ全体を確認するために複数の画像を開く必要がある。1枚の全体画像は、縦長のページほどファイル容量が増える。操作前後は表示範囲を撮り、操作のたびに全体画像を増やさない。初期画像は操作前の文書の記録として扱い、実際のスクロールで現れる内容を観察したかは別に記録する。保存済みの証拠や判定は変更しない。

## 検証方法

ローカルの縦長ページを `page-audit` と `page` で検査する。初期画像の枚数、ページの計測寸法とPNGの一致、ページ末尾のマーカーが描画されること、操作前後のPNGが表示範囲の寸法に収まること、HTMLから画像を開けることを確認する。再開時は取得済みの初期画像のハッシュを照合する。

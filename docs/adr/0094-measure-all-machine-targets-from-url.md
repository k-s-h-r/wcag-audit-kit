# 0094 通常の入口から機械検出対象の全行を測る

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0084](0084-score-machine-findings-from-url-only.md)で、個別の操作条件を指定する回帰試験に加え、URLから操作を見つける範囲を測ることを決めた。T017の8ページの比較を、機械検出を期待する全87行へ広げる。

## 決定

操作条件と期待結果は採点側の一覧に置く。配信するのは公開ページと素材。通常の `wcag-page` にURLと共通設定を渡し、初期取得と簡易探索を行う。終了後、対象・状態・観点に合う、収集時の報告と証拠を照合する。[T020の記録](../../validation/development/T020/README.md)

PC幅とスマホ相当幅の結果を行ごとに残す。同じ問題行は一度だけ数え、対応する問題の判定が一つの幅で確認できれば検出とする。正常の一致には両幅で判定の証拠が必要。状態・経路の未確認、到達後の判定なし、収集失敗を保持する。

## 代替案

取得した操作ログを採点側で評価すれば、実際の指摘に加えて、観察から判定できそうな箇所も分かる。今回は収集時の出力を主成績とし、操作ログから分かる次の改善は別に記録する。

## 影響

既存の検出器・問題集は同じ条件で回帰試験に使う。今回の測定器は新しいrunと採点用の出力を作る。機能への入力と実行結果を照合する改善は[T024](../tasks/T024-keyboard-function-result.md)へ渡す。

## 検証方法

全76ページ・87行の分母と実行コマンドを照合する。対象と状態の一致、二つの幅の集計、入力送出と機能判定の切り分け、対応付けられない指摘が保存されることを確かめる。

# 0023 操作後に現れる画像の機械検査を改善する

日付：2026-11-19 / 状態：Proposed

## 背景

ボタンを押すと表示される画像の回帰例で、`image-alt` の結果を採点できなかった。フォーム外の `button` も既定の `type` が `submit` になるため探索から外れていた。操作しても短いタイマーで追加される画像を固定の待機時間では取り逃がし、取得した非初期状態の機械証拠も問題集の状態へ結び付けられなかった。

## 決定

- ブラウザーが観測したフォームとの関連付けで送信操作を判別する。関連のある送信ボタンと、表示名が保存や購入などを示す操作は引き続き自動操作から外す。
- 初期表示と操作後に、DOMの更新と関数を使う短いタイマーを観察する。更新が止まってから150ms待ち、最大1500msで打ち切る。上限外や追跡できない処理は残る確認に記録する。
- 問題集に公開した操作経路と到達条件が揃ったとき、その状態の機械証拠を採点する。指定は証拠の照合に使う。スクロール調査で画面が変わる前に機械証拠を取得する。

## 代替案と影響

固定の待機時間を伸ばすと、変化のない画面でも待ち続ける。観察上限を設けることで待ち時間を抑えながら、取り切れない範囲を示す。通信・アニメーションなどの完了判定は対象外とする。新しい版では1.1.1の公開状態メタデータを更新するため、別のrunで比較する。

## 検証方法

`benchmarks/run.py collect --mode machine --criterion 1.1.1 --criterion 2.4.2 --out <新しい出力先>` で回帰例を再実行できる。比較対象は画像7行とタイトル3行。フォーム外の操作、関連のある送信操作の保留、短い遅延と上限外のタイマー、スクロールで消える画像の証拠をブラウザー試験で確認する。試験のソースと結果の要約を残し、各runのZIP・画像・ログは開発ブランチの外に保管する。

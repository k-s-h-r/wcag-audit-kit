# 0042 Orcaの発話と直後に続く付加情報を読み取る

日付：2026-11-19 / 状態：Accepted

## 背景

Orca 51.1で実際に「保存しました」を発話した行が、発話文字列と付加情報の間に空白を置かない形式だった。従来の抽出処理は空白か行末を要求していたため、その行を発話として拾えなかった。

## 決定

Orcaの発話ログで、引用された発話の直後に空白を挟まず波括弧で始まる付加情報が置かれる形式も受け取る。発話の文字列、ログ上の行、UTCの時刻を記録する。観察区間と元のログの照合は従来のままとする。

## 代替案と影響

行に文字列が含まれるだけでは、ログの説明と実発話を区別できない。発話行の接頭辞と引用文字列を引き続き確認し、測定した書式差だけに対応する。新しい版の起動方法や必要なパッケージは別の移行作業として扱う。

## 検証方法

`python3 -m unittest discover -s tests -p 'test_orca_log.py'`。従来形式と、実Orca 51.1で観察した隣接形式を比べる。発話の内容と時刻を元のログで照合し、別の種類の行を発話として拾わないことを確認する。

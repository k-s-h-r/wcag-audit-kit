# 0029 フォームとの実際の関連付けで送信操作を区別する

日付：2026-11-18 / 状態：Proposed

## 背景

T003の操作後画像は、フォーム外buttonのDOM type既定値submitによって操作自体が保留されていた。送信操作でないのに検査対象を見落とす。

## 決定

DOMのform関連付けを収集し、明示的にfalseの場合だけsubmit既定値を探索可能にする。フォーム内とform属性による関連付け、保存等のラベルは従来どおり保留する。不明な古い記録は保留し、関連付けの変化を状態識別に含める。問題集や期待判定は変えない。

## 代替案

全submitを許可する案やケースIDで操作を解放する案は採用しない。問題集へtype=buttonを書き足して実装の見落としを隠す案も採用しない。

## 影響

即時の詳細表示を取得できる。元の画像の成績はまだ5/7一致で、短い非同期更新の待機と名前付き状態への採点接続が残る。実装識別値が変わるため別runで確認する。

## 検証方法

専用fixtureで旧実装の見落としを再現し、修正後の画像取得、関連フォームの保留、POST 0件を確認した。208単体試験、元の入力の新規runを保存した。[T009](../../validation/development/T009/README.md)を参照。

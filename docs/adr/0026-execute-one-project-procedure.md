# 0026 対象固有の手順を既存fixtureの1経路で確認する

日付：2026-11-18 / 状態：Proposed

## 背景

T005ではpstackを参考にした準備・到達・操作・復帰・証拠・後片付けを、作成しただけでなく実行して確かめる必要がある。

## 決定

既存のProfile demoでログイン・編集・確認・保存・ログアウトを実行する。既存テンプレートを具体化し、新しい手順エンジンや対象の修正は追加しない。操作の観測とWCAGの判断を分ける。

## 代替案

外部の実アカウントや本番データを使う必要はない。ソースの読解だけで実行成功とする案は採用しない。

## 影響

T011・T012が再利用できる短い経路と後片付けが得られる。実発話・意味判断・全入力経路の実証は別に残る。

## 検証方法

実ブラウザーで6段階とAPIの応答、保存画面を記録し、停止後の接続不能と証拠の可読性を確認した。[T005記録](../../validation/development/T005/README.md)を参照。

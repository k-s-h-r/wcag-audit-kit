# 0056 別サイトで検証の各段階と証拠を照合する

日付：2026-11-19 / 状態：Accepted

## 背景

指定URLの機械検査、タイトルの意味比較、実Orcaでの通知取得を個別に確認した。次は、これらを別の小さなサイトへ適用し、実際に調べた操作と帳票の対応を確認する。[T014](../tasks/T014-site-acceptance.md)

## 決定

検査側には公開URL、調べる範囲、許可された操作を渡す。採点側は別の環境で期待結果とアクセス記録を持つ。最初に候補を抽出し、実際の操作で観測したURLと状態を加え、確定一覧からページ単位で収集する。中断前後の台帳と証拠を照合する。タイトルは保存した本文から判断し、通知は実Orcaと同じ環境での正常対照を確認する。

## 代替案と影響

最初に正解一覧を作業票として渡す手順は、指定された対象を担当するときに使える。今回の試験では、検査側が自ら見つけたページと操作も測る。機械検査の帳票、追加観察、採点の根拠をURLと状態で対応付ける。省略した方法や観察できない範囲は未確認として集計する。

## 検証方法

アクセス記録、ブラウザー操作、保存画像・ツリー・本文、台帳、帳票、モデルの入出力、実Orcaの発話を照合する。報告だけの試行では保存済みrunのコピーを読み、HTTPアクセス、検査記録、証拠ハッシュを比較する。各段階の対象と実測結果は[T014](../tasks/T014-site-acceptance.md)に記録する。

# 0101 ネイティブのモーダルを開いた状態は全体を再検査する

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0076](0076-scope-rechecks-to-operation-impact.md)では、変化していない要素のARIA属性名と `tabindex` の結果を再利用する。HTMLの `dialog.showModal()` でモーダルを開くと、それ以外の文書部分が操作・アクセシビリティの対象外になる。要素のHTMLにはこの変化が現れず、モーダルの背後にある要素の指摘と通過を差分再検査が再利用していた。

## 決定

操作後に `dialog:modal` があれば、axeのルールを絞らずに全文書を検査する。差分再検査を切り替えた理由は `operation-impact.json` に `native_modal` として記録する。状態の取得時とaxeの検査前後で、開いているネイティブモーダルの一覧と `dialog` の `open` 属性の変更回数を比較する。開いている要素が同じでも、閉じて開き直すと前面が変わる。観察の間に変化した経路では状態の違いを記録し、axeの結果の保存を止める。

同じHTMLと操作候補を持つ `dialog.show()` と `dialog.showModal()` でも、検査する範囲は変わる。探索時の状態識別には、ネイティブのモーダルが開いているとき、そのセレクターを含める。複数が開いている場合は、開いた順序によって検査の対象が変わる。モーダルの集合だけでは前面にある要素を特定できないため、観察ごとに状態を分けて検査する。

## 代替案

モーダル外の要素を一件ずつ比較して再利用する方法では、ブラウザーとaxeがその時点で対象とする文書範囲を合わせる必要がある。まず2ルールの結果の一致を確かめるため、モーダルの状態では全文書を使う。CSSで表示される領域や、外部のラベルとポップアップには既存の比較を使える。

## 影響と検証

差分再検査と全文書の再検査を同じ操作・表示幅で比較する。ARIA属性名と `tabindex` の各判定、対象、再利用数を確認し、ほかのaxeルールの結果も照合する。探索の上限、観察した状態と経路、文書リクエスト数は試験記録に残す。 [T019の記録](../../validation/development/T019/README.md)

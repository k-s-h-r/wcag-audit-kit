# 0025 ホストの起動失敗をスキルの呼び出し成功にしない

日付：2026-11-18 / 状態：Proposed

## 背景

T004では設定ファイルの確認とホストの実動作を区別する必要がある。独立コピーした4スキルを使うCodexの新規セッションは、読み取り専用ファイルシステムによりapp-server初期化で停止した。

## 決定

設定の静的確認と原エラーを記録し、5場面のホスト動作を未実施にする。利用者の設定や保護された保存領域を変更せず、実行可能な環境での再試験を条件として残す。T004の調査記録と、T011・G2に必要な呼び出し成功は分ける。

## 代替案

手動でSKILL.mdを読んだ結果をホストの成功にする案や、根拠なく同じ起動を再試行する案は採用しない。

## 影響

機械の基準値と対象固有の操作手順は独立して進められる。ホスト条件を必要とする後続の実AI測定は未達として保持する。

## 検証方法

4スキルのYAMLを解析し、独立コピーと実CLIの入力・stderr・終了状態を確認した。[T004記録](../../validation/development/T004/README.md)を参照。

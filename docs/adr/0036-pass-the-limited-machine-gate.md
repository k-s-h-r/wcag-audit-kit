# 0036 最初の10行の実測に基づき、指定URLの検査へ進む

日付：2026-11-19 / 状態：Accepted

## 背景

T001では1.1.1-01の画像の代替文ルール7行と2.4.2-01のタイトルの有無3行を採点側で固定した。操作後の画像2行には未実施があったが、[ADR 0023](0023-audit-images-after-interaction.md)の収集・採点変更で追跡できるようになった。次の工程を始めるには、同じ10行の再現性、取得記録、残る確認の帳票を照合する必要がある。

## 決定

同じ実装、問題集、ブラウザー、設定の独立した2回の機械検査で、10行すべてが期待結果と一致し、証拠を確認できれば、この選択範囲のG1を達成とする。対象は決定的な収集処理へ渡す公開ページだけとし、期待結果は集計側で使う。操作後の2行は、生のaxe・状態・操作経路を照合する。

ページ単位の報告と4モードの実施記録は[ADR 0033](0033-record-status-acquisition-and-mode-evidence.md)の検証結果を使う。別の観点の未確認、未実施、AI・実スクリーンリーダーへ渡す確認は報告に残す。

次に指定URL一覧で、ページ別の結果と中断・再開を検査する。共有部品は、見た目の文脈やページごとのCSSで結果が変わることを別に確かめる。

## 代替案と影響

すべての達成基準を自動検査できるまで待つと、すでに再現できている限定範囲のページへの展開が遅れる。今回のG1は固定した10行の根拠を持つ範囲で使う。サイト全体の適合、未知のサイトでの精度、G2の達成、実ホストの呼び出しは別に確認する。

## 検証方法

```sh
python3 tests/machine_gate_browser.py --out <新しい出力先>
python3 tests/configured_pages_browser.py --out <別の新しい出力先>
python3 tests/site_selection_browser.py --out <別の新しい出力先>
```

`30edfee`、Chromium 156.0.8078.79、Playwright 1.62.0で、2回とも固定10行は全件一致した。全体の票は一致10・省略8・未確認7、取得は一致2・未確認1で、全体ステータスは未完了だった。対象の誤検出は0件。HTML・Excelの値と証拠リンクも読戻した。

指定7 URLでは収集1・中断1・未試行5から再開し、収集6・404失敗1になった。認証・操作後のページを選ぶ別の試験では、マークアップとARIAが同じフッターでも、ページ別CSSでコントラストの結果が変わった。

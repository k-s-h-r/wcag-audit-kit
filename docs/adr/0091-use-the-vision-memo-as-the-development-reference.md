# 0091 開発計画から完成像を参照する

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0088](0088-center-the-vision-on-conformance.md)でWCAG適合の結論をメモの中心に置き、[ADR 0090](0090-describe-two-audit-purposes-in-the-vision.md)で二つの使い方を加えた。今後の開発の出発点として、どんな力を伸ばすのかも明示したい。

## 決定

[やりたいことメモ](../VISION.md)に、URLから操作を見つけ、問題例と正常例を根拠に基づいて判定できることを前進の目安として書く。[開発計画](../ROADMAP.md)の冒頭から完成像を参照する。

## 代替案

完成像を開発計画へ移す案もあった。完成したらどう使いたいかを短く読めるように、メモを参照先にする。

## 影響

開発を再開するときに、次の作業がどのゴールに向かうのかを確認できる。計測条件と作業ごとの完了条件は担当タスクに記録する。

## 検証方法

開発計画からメモを開き、WCAG適合の結論、二つの成果物、二つの使い方、前進の目安を読み取れるか確認する。前進の目安は[T017の評価方針](../tasks/T017-url-only-exploration.md)と照合する。

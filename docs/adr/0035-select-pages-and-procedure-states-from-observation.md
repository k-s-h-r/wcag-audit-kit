# ADR 0035：候補URLと実操作で見つけた状態を分けて選定する

日付：2026-11-18。状態：提案。対象：T013。起点：T010提案版7f2735b。0034は独立したT012に割り当てる。

## 背景

T006では初期リンクから見つからないURLがあり、T010では指定ページを別runで実行できた。候補発見と監査対象の選定の間に、状態と手続きの情報が必要である。

## 決定

有限の所有サイトで既知の対象を全件選ぶ。候補台帳、選定・除外理由、到達不能、動的な経路とその始点・終点を既存の設定と資料に記録する。configuredのURL一覧は初期ページの引き渡しに使い、同じURLのrevealed状態や手続き完了条件はprocedure.jsonに分けて渡す。状態がURL一覧だけで実行されたとは扱わない。

## 代替案と影響

この小規模な全件選定では無作為抽出を行わない。大規模サイトの代表抽出、自動サイトマップ統合、新しい汎用計画形式は追加しない。共通headerの同じソースは確認できるが、他ページの適合判定へ再利用しない。404は台帳に残す。

## 検証

初期候補10件から隠れたリンクへ実操作し11URLを選定。初期・展開後・完了・戻るの4状態をHTMLと画像で記録した。対象外2URLと404を区別する。両端点を含む既存configured設定を検証し、試験を実施したことやサイト全体の適合へ変換しない。

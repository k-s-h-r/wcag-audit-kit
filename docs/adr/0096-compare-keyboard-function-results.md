# 0096 クリックとキー入力の後で数値表示を照合する

状態：Proposed

## 背景

T020の数量変更では、クリック後は数量が増え、Enter後は変わらなかった。帳票にはキーの送出だけが記録された。別の部品をキーで操作して同じ数量にできる対照もある。[T020の実測](../../validation/development/T020/README.md)

## 決定

単独ページの簡易探索で、初期表示に表示中の数値を返す `output` が一つある場合に、同じ初期状態からクリックとキー操作を試す。対象に届いた実入力、入力直前の値、操作後の値を記録する。EnterとSpaceの片方が通常の探索候補から省かれる場合は、既存の候補に続けて試す。

別の部品で同じ表示値にできる経路は、両部品のラベルと操作後の画面状態も一致する場合に報告する。問題を指摘する範囲は、観測したボタンが一つで、同じボタンへのEnterとSpaceのどちらでも値が変わらない場合に限る。別の操作部品やキー割り当てを観測した場合、入力直前の状態や操作の影響を照合できない場合は、追加確認を残す。

## 代替案

利用者が操作と期待値を指定する方法は、対象固有の試験で使える。今回の対照ではURLと共通設定を受け取り、自動探索の結果から値を照合する。ページ内の文章や属性の変化を一律に機能の結果として扱う方法も検討した。フォーカスの移動や案内の更新を数量変更と混同するため、最初の対象は表示された `output` に絞った。

## 影響と検証

帳票の観点と証拠から、クリック、キー送出、数値の変化をたどれる。達成基準全体の判定は、ほかの機能や経路の確認を含む。配布する4スキルを同期し、通常の入口で既存の数量変更3ケースを比較する。T020と同じ採点行で変更前後を測り、正常例の誤検出と既存の検出を照合する。[T024](../tasks/T024-keyboard-function-result.md)

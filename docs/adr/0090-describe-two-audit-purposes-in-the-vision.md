# 0090 検査を頼む二つの目的を完成像に加える

- 日付 2026-11-21
- 状態 Proposed

## 背景

[ADR 0088](0088-center-the-vision-on-conformance.md)でWCAG適合の判定をスキルの完成像に据えた。Webの開発や運営に関わる人が、利用する人の困りごとから改善を考えられる使い方もほしいという案が出た。

## 決定

[やりたいことメモ](../やりたいことメモ.md)に、WCAGへの適合を確かめるモードと、使う人が困る場面を見つけて改善を提案するアクセシビリティ点検モードを選べる将来像を書く。

## 代替案

WCAG検査票に改善提案を添える形も考えられる。今回の案では、開発や運営のチームが、困りごとを知りたい時点で点検を頼めるようにしたい。

## 影響

メモに、利用者が何を知りたいかで使い方を選ぶ場面が加わる。既存の検査手段を選ぶモードとの関係は、実装を検討するときに決める。

## 検証方法

WCAG検証の二つの成果物を読み取れ、アクセシビリティ点検は具体的にどんな改善を提案するか想像できるか確認する。

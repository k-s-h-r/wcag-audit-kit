# ADR 0037：帳票のセル値と証拠の対応を照合する

日付：2026-11-18。状態：提案。対象：T008のレビュー対応。

## 背景

初回の帳票確認は行数・集計・リンクの存在を検証したが、対象や判定の対応をセル単位で照合していなかった。行数が変わらない誤りを検出できないため、旧記録の「一致」はその確認範囲を超えていた。

## 決定

保存済みJSONを基準に、HTML/Excelの採点表の全セルと、実際の証拠パスの対応を読み取り照合する。未確認取得表のセルも比較する。ページ帳票はチェックシート全セル、HTMLの証拠対応、Excelの機械検査全セルを比較する。旧試験の原文・結果は保持し、新しい確認を別記録にする。

## 代替案と影響

集計だけで一致とする案は採用しない。製品の判定や報告を再生成せず、保存済みの4run・28ページを使う。新しいreport_cell_values.pyは試験補助で、実行時の採点器ではない。表の日本語表示とリンク表示の差は、同一の対象・判定・パスへ対応することを確認する。

## 検証

4runの採点全セル・未確認取得表、28ページのチェックシート全セル・証拠対応・機械検査全セルを照合した。元の4,676ファイルは不変。対象・判定・証拠だけを変えて行数を保ったHTML/Excel計6つの否定例が拒否されることを、メモリー上の変更で確認した。取得一致表を含む後続版にも同じ照合補助を適用できるようにする。

# 0105 画像から読んだ値を、操作後に現れる代替情報と照合する

状態：Proposed

## 背景

以前の試験では、詳細の値が不足した例もAIが通過と答えた。代替文の有無を測っても、図と同じ情報が得られるかは分からない。[T011の実測](../tasks/T011-ai-residual-review.md)

## 決定

画像から値・単位・傾向を取り出し、詳細を開く前に記録する。公開画面から表を開き、代替文が案内する情報と各値を照合する。装飾の図は、操作名や状態を重複していないか別に確認する。

機械検査、画像と代替情報の比較、達成基準全体の結論をそれぞれ記録する。AIの比較結果は、同じURL・環境・検査票へ観察資料を添えて反映する。元の機械runは保持する。

## 代替案と影響

「減少した」という傾向だけを照合すると、途中の月の違いを見落とす。今回のページでは月別の値が目的に含まれるため、全3値を並べて比較した。別の図では、目的に必要な分類や比較内容を画面から確認する。

## 検証

期待する結果を検査役に渡さず、同じ画像で代替値が一致する例と異なる例を確かめる。機械結果、実際に表を開いた記録、報告の添付証拠と結論を照合する。[実測と再現手順](../../validation/development/T011/README.md)

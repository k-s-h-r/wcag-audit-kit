# 0097 保存済みの判定から対象範囲の結論を出す

- 日付 2026-11-21
- 状態 Proposed

## 背景

帳票の `audit_complete` は、予定した検証が完了したかを示す。検証の完了と、対象範囲がWCAGに適合したかは別の問いになる。[T021](../tasks/T021-scope-conformance-report.md)では、利用者が結論から判定と証拠をたどれるようにする。

## 決定

保存済みの検査票と適合要件の確認記録から `scope_conformance` を作る。HTML・JSON・Excelは同じ集計を使う。証拠付きで基準の不適合を確定した検査票があれば、不適合と判定して残る確認も表示する。適合には、対象レベルまでの全検査票と、ページ全体・手続き・アクセシビリティサポート・非干渉の確認がそろうことを求める。根拠が足りない場合は未確認とする。 [W3Cの適合要件](https://www.w3.org/TR/WCAG22/#conformance-reqs)

## 代替案

既存の `audit_complete` に適合の意味を加える案では、不適合を確認して検証を終えた状態を表せない。帳票生成時に保存済みの事実から結論を求めれば、既存の厳密モードの終了コードと過去の台帳を保持できる。

## 影響

結論の対象は帳票に含まれるURLと状態。runの部分出力には、選択範囲の確定した不適合を表示できる。適合の結論には、ページ全体と必要な手続きを含むrunの帳票を使う。報告は保存済みの判定、原始証拠、定義を読み取る。出力時のアクセス先は帳票ファイルに限る。

## 検証方法

固定したローカル向けの試験台帳で、1ページの適合、2ページの不適合と残る確認、機械候補だけがある未確認を照合する。HTML・JSON・Excelの結論、終了コード、証拠への参照と、再出力時に保存済みの元データが一致することを確かめる。 [検証記録](../../validation/development/T021/README.md)

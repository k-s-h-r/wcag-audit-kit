# 0051 共通部品の測定をページ別の参照HTMLで読めるようにする

日付：2026-11-19 / 状態：Accepted

## 背景

ページ別の機械検査で取得した共通部品のコントラスト測定は、指定した対象ごとにJSONで比較できる。人向けのページ検査では、どのページの測定をあわせて読めるか、どの測定に差があるかを、証拠とともに追いたい。[Issue #4](https://github.com/k-s-h-r/wcag-audit-kit/issues/4) [ADR 0047](0047-reference-shared-contrast-observations.md)

## 決定

`shared-contrast` に `--page-exact` と `--out` を一緒に指定すると、バッチ内の1ページを起点とする参照HTMLを新規出力する。指定ページ、同じ測定、異なる測定、比較できないページを表示する。測定の比・条件と、検証済み証拠への相対リンクおよびハッシュを添える。指定ページを測定できなかった場合は、ほかのページの値を比較結果にせず、そのページで得た値として表示する。

## 代替案と影響

バッチ全体のJSONは、処理で使うグループと未確認理由を持つ。参照HTMLは同じ比較を1ページから読む補助資料とし、別の新しい保存先に出力する。元のページ帳票と証拠を参照でき、ページの検査や記録済みの判定の更新は発生しない。同じ測定のグループは、実行済みの初期表示・対象・環境の比較である。各ページの判断には元の検査票を使う。

## 検証方法

`python3 tests/shared_contrast_browser.py --out <新しい保存先>`。Chromiumのバッチで8.6:1が一致する2ページ、同じHTMLでも1.35:1になる1ページ、404と未着手を収集する。参照HTMLの行、ハッシュと証拠のリンク、指定ページの失敗時・証拠改変時の表示を確かめる。幅320pxで読める表示と、元のファイルが変わらないことも照合する。

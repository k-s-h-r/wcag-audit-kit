# 0129 採用した版でVISIONの初回実証を確認する

状態はAccepted。

## 背景

初回実証の各試験は別のPRで始め、統合PR #111で同じ版に取り込んだ。報告と操作の証拠を固定した対照ごとにたどり、採用した版から使えることを確認する。[初回実証の完了条件](../DEVELOPMENT-GOAL.md#初回実証の完了条件) · [統合時の判断](0128-merge-the-vision-pull-requests-together.md)

## 決定

`main` の `a65836a` を初回実証の版として記録する。T024は公開済みの76ページ・87行の実測と採用版の収集・採点コードの一致を確認する。T021・T022は保存した判定や独立した操作の記録から通常のCLIで再出力する。T023は同じ6回のキー入力で改善前後を再比較する。[結果と各試験の根拠](../../validation/development/vision/README.md#初回実証の完了確認)

## 代替案と影響

個々のPRの確認だけで締める方法では、同じ版の帳票に証拠が出るかを確かめられない。初回の操作担当に既知の対照をもう一度渡す方法では、採点情報を伏せて操作した当初の条件を保てない。元の操作と発話の記録を保持し、再出力と改善前後の再実行は新しいrunに分ける。

## 検証

別エージェントが4条件ごとに、事前に固定した条件、判定、操作証拠、帳票、最終回答を照合する。採用版で配布スキルの同期と単体試験を実行し、再出力した帳票と改善前後の結果を確認する。[再確認の集計](../../validation/development/vision/run-003/result.json)

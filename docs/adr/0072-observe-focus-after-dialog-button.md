# 0072 閉じるボタンと次のTabのフォーカスを観測する

日付：2026-11-20 / 状態：Proposed

## 背景

[ADR 0063](0063-observe-focus-after-dismissing-modal.md)の自動探索は、Escapeで閉じたときのフォーカスを記録していた。現行の入力観測が参照する変数名とダイアログ側が設定する変数名がずれ、開く操作の対象を実入力と照合できなくなっていた。モーダルを閉じるボタンからも同じように復帰先を追えるようにする。[Issue #4](https://github.com/k-s-h-r/wcag-audit-kit/issues/4)

## 決定

一つのモーダル内で、自動探索が試すクリック・Enter・Spaceの対象がボタンなら、実入力と前後のモーダルを照合する。ボタン名から用途を推定せず、ダイアログの表示が消えた入力を閉じる操作として扱う。閉じた直後と次のTabの証拠を保持し、ダイアログを開いた同じ要素への復帰を確認する。ボタン操作後も同じダイアログが表示される場合は、その操作の観測を証拠に残す。

閉じた直後にフォーカスが文書自体に戻り、通常のTab順に参加できる開き元より前の要素へ次のTabで戻ったことを確認したら、機械検査に問題を記録する。別の要素にフォーカスした場合は、手続きの続きとして適切かを判断保留にする。モーダルの属性が変わっても同じダイアログが画面に残る場合は、閉じた状態として採点しない。

## 代替案と影響

ラベルで「閉じる」の表記を探す方法では、言語やアイコンが変わると候補を落とす。現在の操作候補を使い、操作によって表示が消えたことを確かめる。次のTabを別経路で観測する方式と既存の探索上限を引き継ぐ。通常の探索はクリック・Enter・Space、簡易探索は既存の優先入力を使う。フォーム送信などの操作制限を維持する。新しい観測は主文書の通常のDOMにある単一のモーダルが対象で、旧runの証拠も引き続き表示できる。

## 検証方法

`python3 tests/dialog_focus_browser.py --out <新しい出力先>`。同じ開き元に戻る例、別の位置へ移る例、文書へ戻り次のTabで開き元より前へ移る例、ボタンを押しても閉じない例、非モーダルに変わった後も画面に表示される例を比較する。従来のEscape経路と簡易探索も実行し、実入力・各フォーカス先・JSON・HTML・Excelを照合する。

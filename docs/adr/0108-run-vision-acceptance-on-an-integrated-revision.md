# 0108 VISIONの検証を一緒に使える版で行う

状態：Proposed

## 背景

URLの探索、キー操作、検査票、点検、修正前後の比較は、別々のPRで進めた。操作の測定を共有するPRもあり、各ブランチの試験だけでは組み合わせた動きを確認できない。通常の `page-audit` で作った検査票を比較した際に、検証で必要なブラウザー情報が不足する組み合わせも見つかった。

## 決定

T023までの実証を起点に、関連PRの内容を同じ作業ブランチに取り込み、通常の入口で動作を確かめる。既存の実測記録は保持する。新しいrunには統合版で再実行した試験と結果を保存する。各PRの採用はリポジトリのマージ規則に従う。

## 代替案と影響

個々のPRの試験は、各変更の動作と根拠を追跡しやすい。統合版を併せて検証すると、複数の変更が同じキー入力や検査票を扱う場合の動作を確かめられる。依存するPRの更新後は、実行した版と変更差を照合して追加試験の範囲を決める。

## 確認の範囲

VISIONの項目と各試験の対象、観測条件、結果を対応付ける。実測していないページ・環境・達成基準は、個別の帳票と同様に未確認として扱う。[統合版の確認](../../validation/development/vision/README.md) · [VISION](../VISION.md)

# 0047 共通部品の同じコントラスト測定をまとめて参照する

日付：2026-11-19 / 状態：Accepted

## 背景

指定URL一覧のページ別機械検査では、共通フッターなどの同じ測定を何度も読むことがある。同じHTMLとアクセシビリティツリーのリンクでも、ページのCSSで実際のコントラストが異なる例があった。

## 決定

`shared-contrast` は、既存の機械検査バッチから、指定した環境の初期表示で、axeの `color-contrast` が示した一つの対象を読む。元の測定値・測定条件・対象ノードが一致した場合に測定をまとめ、すべてのページ、収集状態、元の証拠とハッシュを保持する。測定が異なるページは別の結果へ出し、未収集・測定不能・証拠不一致は理由を残す。

## 代替案と影響

共通部品のHTML一致だけで検査結果を流用すると、祖先の色や適用されるスタイルが異なる問題を見落とす。ページごとの観察を行った後に、検査者が同じ測定を読み直す手間を減らす。検査の回数と、他の状態・観点・達成基準の判定は、それぞれのページ記録が扱う。

## 検証方法

`python3 tests/shared_contrast_browser.py --out <新しい保存先>` を実行する。実際の機械検査バッチでは、8.6の2ページが一つにまとまり、同じHTMLで1.35だったページが別に出た。404、未着手、証拠を改変したコピーも確認した。実行コマンドから同じ結果が得られる。

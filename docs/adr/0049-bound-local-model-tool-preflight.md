# 0049 ローカルモデルのツール呼び出しを予備試験として扱う

日付：2026-11-19 / 状態：Accepted

## 背景

隔離した実Codexで、選んだスキルの本文がモデル入力へ展開されることを確認した。外部モデルへの接続がない環境で、実モデルからCodexのツールを呼び出せるか調べるため、公開モデルをローカルで試した。

## 決定

読み取り専用の試験ファイルを一つ用意し、Codexに明示指定した `wcag-page` とともに、内容を読み取る依頼を渡す。モデルからのツール要求、ツールの完了と取得値、最後の応答を個別に確認する。予定した読み取りができても、ページの検査、報告、親スキルから子手順への引き継ぎは実行できる環境でそれぞれ確認する。

## 代替案と影響

取得したファイルの内容と最終応答を同じ成功にまとめると、ツールは動くが依頼が完了しない構成を見落とす。ローカルモデルの試行は接続とツール動作の予備確認に使い、モデルの選択は具体的な作業を完了できることから判断する。

## 検証方法

Debian 13の一時コンテナにCodex CLI 0.167.0-alpha.4、Ollama 0.40.16、Qwen3-VL 2Bを配置し、コンテナ内のループバックだけで実行した。配布ファイルとモデルのハッシュを取得元と照合した。`codex exec --oss --local-provider ollama --ephemeral --json -s read-only` にモデル、`model_provider="ollama"`、`$wcag-page` を指定した。

Instruct版で、試験ファイルだけを読むMCPツールが完了し、想定した内容を2試行で取得した。どちらも最終応答は時間内に完了しなかった。シェルを使う試行では引数の検証でコマンドが実行されなかった。採点・判定・ユーザーの設定は元の記録を保持した。

# 0061 指定ページの文字コントラストを画素で測る

日付：2026-11-19 / 状態：Accepted

## 背景

問題集では指定した文字列の描画色を変え、実際の前景色と文字の下にある背景色をChromiumの画素から得られた。通常の1ページ検査でも、指定した文字の測定値をページ別の帳票から読めるようにする。[ADR 0032](0032-verify-visual-evidence-in-isolation.md) [ADR 0035](0035-grade-opt-in-text-paint-evidence.md)

## 決定

`page-audit` の `text_contrast_checks` に指定した要素の初期表示を、測定ごとに独立したブラウザーコンテキストで開く。測定開始後の通信を遮断し、測定用の文字色に対応する変更以外のDOM変化を監視する。透明・黒・白の描画を使う問題集と同じ画素計測を使い、元の描画・復元後の描画とそれぞれの再取得が一致する条件で値を採用する。達成基準の閾値との比較には丸め前の値を使う。

測定範囲は主文書の `p`、`span`、`div`、`label` の直下にある1行の文字。複雑な描画、埋め込み、覆い、表示範囲外、測定中の構造変化や通信は保留する。表示範囲全体は差分の照合に使い、各測定のPNGは文字周辺だけを最大7枚保存する。

## 代替案と影響

通常の探索と同じブラウザーコンテキストで色を変えると、その後の操作や証拠に影響する。通常探索と独立した再訪問1回に絞り、測定結果はその初期表示に対応させる。CSS上の色だけで計算すると透明や重なりを見落とすため、画素を照合して保留を残す。画像収集の設定にかかわらず、明示した測定にだけ画像を保存する。達成基準の例外やページ全体の適否は既存の検査票で確認する。

## 検証方法

`python3 tests/page_text_contrast_browser.py --out <新しい出力先>` で、通常文字の2.32:1と18.88:1、大きな太字の4.48:1を確認する。途中再開で以前の証拠を保持し、重なり・DOM変化・測定中の通信を保留すること、HTML・JSON・Excelと切り出した画像の証拠が対応することを確認する。既存の問題集は `python3 tests/text_paint_probe_browser.py --out <別の新しい出力先>` で再検査する。

# 0031 操作対象のCSS寸法と辺間隔を取得期待に照合する

日付：2026-11-19 / 状態：Accepted

## 背景

2.5.8の既存例には操作対象の寸法と間隔を決めた取得期待がある。ブラウザーが初期表示の矩形を保存しても、採点では取得を未確認としていた。

## 決定

2.5.8-01のうち、取得期待が2対象の幅・高さ・辺間隔を指定する場合に限り、測定を照合する。[ADR 0029](0029-match-initial-image-inventory-evidence.md)と同じ初期表示の受領記録・マニフェスト・操作記録・要素一覧を使う。両対象のセレクターが一意で、矩形が有限・表示中で、水平か垂直の一列にそろうことを確かめる。重ならない二つの矩形の辺間隔をCSS pxで計算する。

一致した取得はJSON・HTML・Excelに寸法、間隔、証拠を出す。未確認の取得と達成基準の判定は別に管理する。斜めの配置、重なり、不完全な取得、文中リンクの例外はこの照合では保留する。

## 代替案と影響

要素の矩形を使って達成基準全体を自動採点すると、拡大された実際の入力領域、重なり、他の近接対象や例外を見逃す。今回は取得の一致だけを対象とする。保存済みrunと問題集は保持し、新しいrunで検証する。

## 検証方法

```sh
python3 benchmarks/run.py collect --mode machine --criterion 1.1.1 --criterion 2.4.2 --criterion 2.5.8 --out <新しい出力先>
python3 benchmarks/run.py score --strict --run <同じ出力先>
python3 tests/benchmark_report_browser.py --report <出力された帳票ディレクトリー> --out <新しい確認先>
```

Chromiumでは既存の2ページで16×16と28×28 CSS px、いずれも辺間隔2 CSS pxが一致した。2.5.8の文中リンク1件は未確認。1.1.1の取得一致2件と合わせて4件が一致し、取得2件が未確認だった。判定の10件一致、モードによる省略10件、未確認12件は変わらず、厳格採点は終了コード2だった。

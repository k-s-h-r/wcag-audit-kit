# 0099 操作のつまずきと改善を同じ経路で比べる

- 日付 2026-11-21
- 状態 Proposed

## 背景

T022では見学予約の途中でキーによる増員ができず、確認ボタンの表示と名前も異なった。開発・運営担当が改善を試せるよう、操作ログと検査票を使って点検レポートを作る。 [T023](../tasks/T023-accessibility-review-pilot.md)

## 決定

問題例を別のローカル環境に複製し、増員ボタンのHTML要素と確認ボタンの名前を変更する。変更前後に同じキー入力を送り、到達した画面とアクセシブルな名前を比較する。点検レポートには停止点、変更箇所、比較結果、元の不適合判定への参照を載せる。

## 代替案

提案文だけを返す方法では、この手続きで確認画面まで進めるかを確かめる作業が読者に残る。複製したページで先に比較し、読者が試す操作と確認する結果を示す。

## 影響と検証

新しい試験は `validation/development/T023/` に保存する。T022の判定と添付証拠を参照し、同じ元の操作記録がSHA-256で一致することを確かめる。別の読み手はレポート本文をもとに、変更する箇所と操作手順を説明する。検証はローカルの一経路で行う。 [点検レポートと再現手順](../../validation/development/T023/README.md)

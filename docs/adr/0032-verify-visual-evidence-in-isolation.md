# 0032 視覚情報の測定と候補収集を独立した検査で試す

日付：2026-11-19 / 状態：Accepted

## 背景

通常の文字コントラスト検査では、CSSの色と実際に描画された色が、前面の覆い・透明度・画像などで一致しないことがある。見出しやリストに見える段落も、整形の特徴だけでは文書構造としての役割を確定できない。

## 決定

1.4.3の追加測定は、手元にあるHTMLと対象を指定する独立したChromium検査として試す。HTMLを新規のブラウザーコンテキストで表示し、他の通信とページのスクリプトを制限する。文字色を変える前、背景だけ、黒と白の比較、元の描画へ戻した後の画素を確認する。対象・表示位置・描画が安定し、実際の前景と隣接する背景を取れた場合に比を出す。複雑な描画や情報不足は保留する。対象のソースと元の実行証拠を保持する。

1.3.1に関連する、見た目が同じ段落・ネイティブHTML・ARIAの対照をChromiumで実測する。見出しや箇条書きに見える要素は、視覚的な特徴とアクセシビリティツリーを確認した上で、意味判断の候補として返す。

対象固有の操作とURL一覧化も、通常の検査や過去のrunを変えずに再実行できるブラウザー試験を残す。ログインから片付けまでの操作、指定・初期リンク抽出の違い、訪問失敗と上限を別々に確認する。画像や操作ログなどは新しい実行先に書き出す。

## 代替案と影響

通常のページ検査の最中にCSSを変更すると、入力、ページ処理や証拠採取に影響する。別の検査で静的なローカルHTMLに範囲を絞り、得られた値を追加の確認に使う。WCAGの適合判定は元の検査票で扱う。

## 検証方法

`python3 benchmarks/text_paint_probe.py --html benchmarks/cases/1.4.3/public/p01.html --target '#subject' --out <新しい保存先>`で1例を取得する。同じ手順で正常例も測り、描画の確定が難しい対照は比を報告せず保留されることを確かめる。

`python3 tests/project_procedure_browser.py --out <新しい保存先>`と`python3 tests/url_selection_browser.py --out <別の新しい保存先>`で、対象操作とURL一覧を再確認する。

Chromium 156で1.4.3の既存2例と大きな太字の対照1例を測定し、半透明・覆い・配置の変化など9例は保留にした。外部リソースの対照では実際の通信は0件だった。`python3 tests/text_paint_probe_browser.py --out <新しい保存先>`で再実行できる。

`python3 tests/visual_structure_probe_browser.py --out <新しい保存先>`で11例を比較する。ネイティブとARIAの構造は、画素が同一でも候補から除けた。見出しと同じ装飾のリード文は候補に残るため、意味の確認に回す。

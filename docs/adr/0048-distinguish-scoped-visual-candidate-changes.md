# 0048 指定範囲の見出し・リスト候補が変わった状態を保存する

日付：2026-11-19 / 状態：Accepted

## 背景

実クリック後にCSSで段落を大きく太くしても、DOM・役割・色が同じ場合は既存の探索で初期表示と同じ状態にまとまった。操作後の候補を集める設定でも、変化後の見出し候補が検査票へ届かなかった。

## 決定

`visual_structure_states: explored` を選んだとき、指定した領域の表示から、見出し風の段落の組とリスト風の段落の並びを重複判定に使う。収集した表示情報を、その状態のアクセシビリティツリーとの照合にも使う。候補を調べる一経路の観察と照合は、合わせて5秒を上限とする。

## 代替案と影響

ページ全体のあらゆるスタイルを状態の識別に使うと、装飾の細かな違いだけで探索が広がる。設定で指定した範囲と候補の変化に絞る。候補の種類や対象が変わらない装飾の差は、この仕組みでは同じ状態として扱う。

## 検証方法

`python3 tests/visual_structure_probe_browser.py --out <新しい保存先>` を実行する。Chromiumで同じ5操作を比較した。指定範囲内に見出し風の表示を作るクリックによって、1状態・候補なしから2状態・候補1件になった。範囲外・既定・未設定では1状態、探索上限を1状態にした試行では1操作だった。

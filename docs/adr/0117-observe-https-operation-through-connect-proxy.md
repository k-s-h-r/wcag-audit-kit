# 0117 HTTPSの操作通信を接続先ごとに測る

状態：Proposed

## 背景

[ADR 0110](0110-measure-cross-origin-requests-during-operation.md)の試験では、通信を受け取る二つのHTTPオリジンを使った。HTTPSの接続先を制限した場合にも、ブラウザーが許可先へ到達し、別オリジンへ要求が届かないか確かめる。

## 決定

同じループバックアドレスの別ポートでHTTPSを受け付ける。プロキシを用いる条件では、元ページの接続先にだけ `CONNECT` を許可する。TLSは両条件でブラウザーと受信先の間に張る。ブラウザーには、この試験で作った証明書の公開鍵を指定する。

## 代替案と影響

TLSをプロキシで終端すると暗号化される前のHTTPを検査できる。今回は接続先の制限を測るので、HTTPの中身は受信先で観察する。許可したトンネル内のパス・メソッドの制限や、プロキシを使わない通信の制限は、別の仕組みと検証が必要になる。

## 検証

直接接続とプロキシ経由の両方で、通常CLIから初期表示とEnterの操作を両画面幅で確認する。別オリジンの受信、許可したオリジンの受信、操作後の表示、継続確認の項目を照合する。[実測と再実行](../../validation/development/T031/https.md)

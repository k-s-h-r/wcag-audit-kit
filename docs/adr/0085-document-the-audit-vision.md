# 0085 WCAG検証の完成像をメモにまとめる

- 日付 2026-11-21
- 状態 Proposed

## 背景

[やりたいことメモ](../VISION.md)の下書きには、人手を介さずにWCAG検証を進める目標と、機械・AIで確認したい例がある。[開発計画](../ROADMAP.md)には、目標に向けた実装・評価の段階を記載してきた。

## 決定

下書きの文言を残し、利用者から見た完成形を追記する。URLから始める検査、実スクリーンリーダーでの証拠、サイト全体を頼む場合、結果の読み方、URL単独の成績で品質を測る考え方を記す。内容は既存の開発方針と、今回のURL単独検査の議論に沿って整理する。

## 代替案

完成像をロードマップだけに追記すると、利用者が受け取る結果を知りたい人も、開発段階や実測の詳細から読み始めることになる。メモで完成像を読めるようにし、進捗と試験の詳細は開発計画を参照できるようにする。

## 影響

メモは目標とする利用体験を表す。既存の実装や検証結果の状態は開発計画と各タスクで管理する。

## 検証方法

元の下書きの見出しと箇条書きを照合する。追記した目標が開発計画や設計方針と整合し、段階的な到達目標と実装済みの能力を混同していないかを確認する。文書間の相対リンクを確かめる。

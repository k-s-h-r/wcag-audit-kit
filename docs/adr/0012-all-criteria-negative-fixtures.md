# 0012 全達成基準に検証用の問題例を用意する

日付：2026-11-17 / 状態：Proposed

## 背景

[ADR 0011](0011-criterion-regression-corpus.md)では7基準の問題集と採点の仕組みを用意した。利用者から全項目への拡張と、今回はTDDの間違いのテストに相当するHTMLを作ることが目的で、検出できるようにする実装は今後でよいとの指定があった。

## 決定

残る79基準に問題例と対照例を追加する。合計86基準・176ケース・184ページ分の入力・185期待結果とする。既存の7基準と保存済みの証拠は変更しない。検出実装・採点器・モードの対応範囲を拡張する変更は含めない。

各基準のpublic内にHTMLと必要な素材を同梱する。操作後・複数ページ・貼付け・メディアの利用条件を明記する。ライブの対照はブラウザー内で生成するストリームを使う。閃光の例は明示的な開始後だけ点滅する。再生を避けるための時系列資料も同梱し、今回の読み込み確認では点滅を開始しない。

音声解説・手話・拡張解説の適合素材を作成したと偽らない。1.2.5・1.2.6・1.2.7は問題例と非適用の対照とし、適合正例の不足を明記する。収録範囲は89確認観点で、残る42観点と各基準の全パターンは未収録と表示する。

## 代替案

検証器の実装・精度評価まで同時に進める案は、今回の利用者の指定を超える。空のHTMLや説明文だけを全基準に配置する案では、意図した問題を操作・観察できない。専門的な素材を外見だけで適合例とする案は、誤った正解をテストへ入れてしまう。

## 影響

テスト入力を先に利用し、後から検出器の実装を進められる。作成者による有限の対照例であり、専門家による独立した正解確認は残る。全86基準にページがあることと、全131確認観点・実環境の精度を検証済みであることを区別する。

## 検証方法

全86基準の問題例、非適用を適合例へ変えないこと、素材・参照先の存在、ページの読み込みとJavaScriptエラーを確認する。ライブの生成、貼付け、再入力、ドラッグの代替等は実ブラウザーで操作する。これらはテストページの動作確認で、検証器が検出できた件数には加算しない。

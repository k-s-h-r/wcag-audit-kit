# やりたいこと

- webページのWCAGチェックを行える
- 機械でできるところは機械で、機械でできない部分はAIで行いたい
- 人間が行うようなWCAGチェックを人間なしで行えるようにすることが最終目標

URLを渡して「ここをチェックして」と頼んだら、メニューを開いた先や、フォームでエラーが出たときも見てほしい。

スクリーンリーダーで使ったときに、実際に何が聞こえるかも確かめたい。

## 機械でやりたい部分

- AXEのような自動検査
- HTMLが正しく利用されているか
- キーボードの閉じ込めがないか
- キーボードだけでボタンやフォームを使えるか

## AIでやりたい部分

- 画像のaltが正しく入っているか
- 画像が装飾か装飾じゃないか判断
- 音声や動画の代替があるか
- 字幕や音声解説で、元の映像や音声の大事なところが伝わるか
- リンクやボタンの名前を読んで、押すと何が起きるか想像できるか
- 見出しを追ったときに、どこに何が書いてあるか分かるか
- 入力を間違えたとき、どこをどう直せばいいか伝わるか

## 結果はこう返してほしい

- どの画面で何をしようとすると困るのかが伝わる
- 画面と試した操作が残り、修正する人も同じ問題を再現できる
- 確認できたところと、まだ確かめられていないところが分かる
- 直したあとにもう一度頼んで、前の結果と比べられる

# やりたいこと

- webページのWCAGチェックを行える
- 機械でできるところは機械で、機械でできない部分はAIで行いたい
- 人間が行うようなWCAGチェックを人間なしで行えるようにすることが最終目標

URLを渡して「ここをチェックして」と頼んだら、メニューを開いた先や、フォームでエラーが出たときも見てほしい。問題が見つかったら、自分でも同じ操作で確かめたい。

スクリーンリーダーで使ったときに、実際に何が聞こえるかも確かめたい。

## 機械でやりたい部分

- AXEのような自動検査
- HTMLが正しく利用されているか
- キーボードの閉じ込めがないか
- キーボードだけでボタンやフォームを使えるか

## AIでやりたい部分

- 画像のaltが正しく入っているか
- 画像が装飾か装飾じゃないか判断
- 音声や動画の代替があるか

# T028 字幕・書き起こし・音声解説を実際の再生と比べる

状態　選んだ7件の実測と照合を完了。[PR #96](https://github.com/k-s-h-r/wcag-audit-kit/pull/96)

前提は[媒体の実表示と音声認識の校正](../../validation/media/README.md)。`codex/t028-observe-media-alternatives` をmainの `67aa42e` から分岐した。

既存の媒体試験では字幕の表示と音声認識をそれぞれ確認した。VISIONで挙げた字幕、書き起こし、音声解説について、実際に再生した媒体の選んだ事実と代替の内容を比較する。[VISION](../VISION.md#機械とaiに任せたいこと)

## 作業と成果物

3ページで共通の原本音声をデコードし、Whisper.cppとChromiumで認識結果と字幕の実表示を記録する。元動画の「Saved」表示を使い、この情報を含む書き起こしと省く対照を比べる。音声解説は同じ映像で説明を加えた音声と加えていない対照をデコードする。選んだ時刻と事実、比較条件を事前に固定し、原始証拠と実行方法を `validation/development/T028/` の記録に結び付ける。

## 完了条件と確認

- 3ページで同じ音声を使い、指定時刻の表示を原始画像とプレーヤーの操作ログから追える。
- 書き起こしと音声解説は、固定した視覚情報を伝える例と省く例を、画面・テキスト・デコード音声で比べられる。
- 事前に選んだ事実の結果を示し、全発話、非言語音、発話境界、全区間の代替、他環境に残る確認を記す。

## 担当範囲と引き継ぎ

T028の対照と実測スクリプト、報告を担当する。既存の媒体記録は元のrunに残す。字幕の実画像は別の担当者が確認し、機械的に取得したcueと照合する。[ADR 0106](../adr/0106-observe-selected-media-alternative-facts.md) · [実測記録](../../validation/development/T028/README.md)

Chromiumの実画面とWhisper.cppのデコード音声の認識結果で、字幕3件、書き起こし2件、音声解説2件が期待と一致した。全発話、非言語音、正確な発話境界、ほかの媒体への適用は確認が残る。[観察結果](../../validation/development/T028/run-002/observed.json)

## 音声解説の選択後に再生された内容を確認

検査票は選択後の状態に証拠を紐付けた。c03の不適合と、c04で観察した観点の通過を記録し、c04の基準全体は判断保留とした。受付コード以外の情報や別環境まで検査する場合は、新しい条件と観察区間を固定して同じ手順で試す。

# T011：機械検査に残った意味判断をAIで確認する

状態：前提待ち、実AIの検証は未実施。開始条件：G1、T004の使用環境での呼び出し成功、T005。

まず画像と代替文の意味、タイトルと主題の対応を小さく測る。機械検査で確定した結果を保持し、AIで追加解決した範囲を示す。

## 作業と成果物

対象は`1.1.1-04`と`2.4.2-02`から、必要な実画像・本文・操作結果を取得できる例を事前に選ぶ。新しいaiモードのrunで、利用先のAIがスキルを明示して実際に観察・判断・記録する。正解を文脈とファイルアクセスから隔離し、採点は別担当とする。

渡した証拠の量、判断の根拠、誤り・未確認、追加で解決した件数、実行時間と取得できるトークン数を残す。画像を保存したことだけで観察済みにしない。新しい状態を発見したら機械検査へ戻す。別runの証拠再利用は、対象・状態・環境・版と出所を検証できる実装がある範囲に限る。

成果物は`validation/development/T011/`の実AI実行記録、観察、判定、証拠、採点、費用、必要なら測定に基づく小さな指示修正。

## 完了条件と確認

- 実際のAIによる実行と採点を再現でき、モデル・環境・版が分かる。
- 正常例と問題例の結果、未確認、費用を隠さず報告する。
- 選択範囲の能力達成は、必要な判定・取得期待の一致と未確認の有無から別途判断する。
- 追加の実SR確認や、まだ試していない意味判断は残る課題として示す。

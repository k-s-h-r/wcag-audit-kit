# T017 URLだけで始める1ページ検査の成績を測る

状態：8ページの測定完了。機械検出対象の全87行への拡張は[T020](T020-url-only-machine-score.md)へ渡す。前提：T007・T009の既存の問題集と実測。関連：[Issue #4](https://github.com/k-s-h-r/wcag-audit-kit/issues/4)・[Issue #69](https://github.com/k-s-h-r/wcag-audit-kit/issues/69)。

既存の問題集では機械検出対象87件が期待どおりだった。一部は操作条件を事前に指定して取得した結果を使っている。普段の `wcag-page` が、URLだけでどこまで操作を見つけて結果を出せるかを測る。基盤は [T009](T009-machine-gap.md) を引き継ぐ。

## 作業と成果物

通常版 `wcag-page` のCLIを使い、両画面幅で初期画面を検査してから簡易探索を実行する。同じページを同じ上限で通常探索した結果と比べる。既存の問題例と正常例から、操作後に追加される画像、3階層メニュー、コンボボックス、閉じた後のフォーカスを調べるダイアログを選ぶ。検査にはURLと通常の実行オプションを渡し、対象・経路・期待結果は収集後の照合に使う。

成果物は [計測コマンド](../../benchmarks/url_only.py) と集計、操作や判定を確認できる証拠の参照。出力先を実行ごとに分け、原始証拠や画像をGitへ追加しない。

## 完了条件と確認

- 簡易探索と通常探索を同じ8ページ・2画面幅で実行できる。操作が見つからなかった、見つかったが判定が出なかった、期待と一致した、判定が異なった場合を区別する。
- ケース、画面幅、入力の種類、判定の元になった証拠を追える。異なる入力の結果からキー操作の成功を推定しない。
- 取得できなかった経路も計測結果として残す。検出能力の改善は[T018](T018-widget-operation-sequences.md)と[T019](T019-post-operation-rechecks.md)へ渡す。

## 担当範囲と引き継ぎ

起点は `dcfd895`、作業ブランチは `codex/t017-measure-url-only-exploration`。別worktreeと新規出力先で、ローカルHTTPサーバー上の公開HTMLをChromiumで検査する。計測コマンドと開発文書を担当する。次は測定で不足が確認された入力から、操作経路を改善する。

## 実測結果

Chromium 156／Playwright 1.62.0で8ページを両幅で実行した。簡易探索と通常探索は最大24ステップ、16状態、深さ3。ダイアログは閉じる入力3種類を個別に測るため、各探索の照合数は24件。

| 操作 | 簡易探索で期待と一致 | 通常探索で期待と一致 | 未確認の内容 |
| --- | ---: | ---: | --- |
| 操作後に追加される画像 | 4 / 4 | 4 / 4 | 両探索とも代替文のある画像とない画像を区別した |
| 3階層メニューをキーだけで開く | 0 / 4 | 0 / 4 | 簡易探索はクリックを含む経路で末端リンクを表示した。キーだけの経路は両探索で未確認 |
| コンボボックスの候補をキーで開く | 0 / 4 | 0 / 4 | ArrowDownで候補が表示される経路を両探索で確認できなかった |
| ダイアログを閉じてTabで移動する | 8 / 12 | 0 / 12 | 簡易探索はクリック・Enterの全件で判定が一致し、Spaceは未確認。通常探索は閉じた後のTabまでの経路を確認できなかった |
| 合計 | 12 / 24 | 4 / 24 | 簡易探索12件、通常探索20件は経路未確認。判定が出た範囲で誤検出や誤判定は0件 |

簡易探索のメニューでは、最初の開閉ボタンのクリックとEnterで同じ画面状態が記録された。クリックの後は次の階層へ進む経路を作ったが、Enterの後には作らなかった。コンボボックスは、簡易探索の待ち行列が空になっても、入力欄にArrowDownを送っていなかった。次の [T018](T018-widget-operation-sequences.md) で、まずメニューのキー経路をクリック経路と別に継続できるようにする。

`python3 benchmarks/url_only.py --out <新規の出力先>` で再実行する。今回の問題集ハッシュは `b4dfb2dd019dc75e8ce34439daf3cd0e05af532da4ed62ca0b197be9d6da1206`。48行の証拠参照を確認し、32本の実行コマンドに個別設定や基準指定がないことを照合した。Python試験313件が通過した。 [PR #76](https://github.com/k-s-h-r/wcag-audit-kit/pull/76) · [ADR 0077](../adr/0077-measure-url-only-operation-exploration.md)

レビュー後は、初期の検査記録を作れない失敗を再現し、PC幅とスマホ相当幅の両方に収集失敗が記録されることを確かめた。

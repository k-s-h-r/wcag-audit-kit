# T044 URL起点の機械ベンチマークを一括採点して比較する

前提はT020の採点とT037の統合結果。URL起点の全87行について、修正後に正解・判定済みの件数と前回から変わった行を一つのレポートで確認できるようにする。[T020](T020-url-only-machine-score.md) · [統合版の採点](../../validation/development/vision-follow-up/README.md#mainへの統合)

## 作業と成果物

ベンチマークの収集と採点を一つのコマンドで実行し、集計と全行の状態・証拠をHTMLとJSONに保存する。基準の採点JSONを指定した場合は、指標の増減と回帰・改善・その他の変化を表示する。基準の分母に未確認の行を含める。[ADR 0130](../adr/0130-report-url-only-benchmark-regressions.md) · [実行方法](../../benchmarks/README.md#一括で採点し前回と比較する)

## 完了条件と確認

- 保存済みの正解とすべての行を照合し、一致と判定済みの件数、問題の検出と対照の一致、未確認・収集失敗を確認できる。
- 前回から正解を失った行と正解になった行を特定する。合計が同じでも、回帰を終了コード1で検出する。
- 収集・採点の条件が異なるときは比較できない理由を返す。既存runを採点するときは新しい出力先を使い、テストページや元の証拠を保持する。

# T029 予約カレンダーの空き状況を色以外で見分ける

[VISION](../VISION.md#機械とaiに任せたいこと)の予約カレンダーを対象に、URLから到達したAIが画面と操作を確かめ、WCAG 2.2の1.4.1の選んだ観点を判断できるか調べる。[T011](T011-ai-residual-review.md)の機械検査とAI観察の分担を使う。

状態は固定した2例で測定と帳票の照合を完了。機械の判定は0/2で、独立した画面・操作の観察では2/2が期待どおりだった。m85cの対象通過は検査票全体の判断保留と併記し、u47bは既知の不適合と未確認を併記した。[PR #97](https://github.com/k-s-h-r/wcag-audit-kit/pull/97)

## 作業と完了条件

同じ日付・操作の対照を用意して、選択前の視覚的な手がかり、画面幅、採点項目を固定する。既存CLIで入口からカレンダーへ到達し、機械の指摘と未確認を保存する。独立した検査担当は各サイトで選択前と操作後を確かめ、手がかりと操作結果の違いを証拠付きで説明する。

観察と採点の一致を確かめた後、通常のCLIから同じページ・表示状態・環境の検査票に記録する。HTML・JSON・Excelと不適合箇所一覧で、根拠と残る確認を照合する。

## 担当範囲

mainの `67aa42e` から `codex/t029-audit-availability-without-color` の別worktreeを使う。対象と実測は `validation/development/T029/` に保存する。ブラウザーはヘッドレスとし、正解の資料は検査担当へ渡さない。 [ADR 0107](../adr/0107-audit-availability-without-color.md) · [試験記録](../../validation/development/T029/README.md)

観察はローカルの一週間分、Chromiumの1画面幅。別のサイト・画面幅への展開、空き状況以外の色の用途、選択後の状態の1.4.1は未確認。

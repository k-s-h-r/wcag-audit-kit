# T018 部品の開閉とキーボード操作を一つの経路で検査する

状態：未着手。前提：[T017](T017-url-only-exploration.md)。関連：[Issue #4](https://github.com/k-s-h-r/wcag-audit-kit/issues/4)・[Issue #69](https://github.com/k-s-h-r/wcag-audit-kit/issues/69)。

自動探索は、個々のクリックやキー入力に加え、先行操作で開いた部品の次の操作まで調べる必要がある。URLだけで届かなかった経路をT017の結果から選ぶ。

## 作業と成果物

アコーディオンは開く・中へTabで進む・閉じる、コンボボックスは開く・候補へ進む・選ぶか取り消す、3階層メニューは各階層を開く・末端へ進む・閉じて戻る操作を調べる。T017では、最初の開閉をクリックした経路からは次の階層へ進んだが、同じ画面に到達したEnterの経路からは進まなかった。まずこの問題を3階層メニューの問題例と対照例で再現して直す。コンボボックスの入力欄ではArrowDownを候補にする条件を確かめる。アコーディオンの開閉とフォーカスの回帰試験も追加する。

## 完了条件と確認

- URLだけの検査で、先行操作の結果から次の入力を選び、同じ経路上で表示とフォーカスを追える。
- 対照例で実入力が通り、問題例の失敗した入力・状態が判別できる。ポインターで到達した結果をキーだけの到達と区別する。
- 再試験で、見つかった経路・判定・未確認の数と、既存の問題例への影響を比較できる。

## 担当範囲と引き継ぎ

操作候補、経路の優先順位、入力とフォーカスの記録を担当する。canonicalの `page_explorer.py`、`page_explorer.js` を変更する場合は同期先も更新する。T019と同じファイルを編集する場合は、先に扱う経路と合流順を決める。証拠は新規runへ保存する。

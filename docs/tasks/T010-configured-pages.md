# T010：安定した機械検査を指定URL一覧へ適用する

状態：指定URL・実中断・再開・ページ帳票の評価完了（PR提案、main未採用）。開始条件：限定G1のT018/T007提案コードとT006。AI・実SRの完成を待たずに進める。

指定された複数URLに対し、実証済みの1ページ検査を適用する。結果の取り違え、中断時の抜け、全体集計の不一致を確認する。

## 作業と成果物

T006の指定一覧を使い、成功するページと訪問に失敗するページを含む小さな複数ページを検査する。対象URL・状態・環境・タスク・結果・証拠の対応を記録し、似たパスや異なるクエリーの結果が混ざらないことを確認する。

途中で止め、同じ実装と条件で未完了分を再開する。ページ別の成功、失敗、未実施と全体集計を照合し、T008で確認した残作業を保持する。機械検査の安定した範囲だけを評価し、全AAの検証完了にしない。

成果物は`validation/development/T010/`の一覧、各run、中断・再開記録、ページ別と全体の対応。問題がある場合だけ、小さな全体進行の修正を加える。

## 完了条件と確認

- 指定一覧の各URLに、結果又は未実施・失敗理由がある。
- 中断後に未完了分へ戻れ、完了済みの証拠を失わない。
- ページ別と集計の件数・根拠が一致し、意図しない巡回をしない。
- G2の達成可否を、使用した実装とrunで説明できる。

## 担当範囲と引き継ぎ

全体進行とページ担当の接続、タスク・再開処理を担当する。CLIの`audit.py`等を修正する場合は、その期間の編集担当を一人にする。URL収集器、AI判断、実SRアダプターはこのタスクで広げない。

完了時に記載する情報：指定一覧、実行条件、各URLの結果、再開方法、全体集計、G2に残る問題。

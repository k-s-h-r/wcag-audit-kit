# T002：タイトルの存在確認を機械で測定する

状態：限定3行の基準値を測定済み。参照先は[基準値 #16](https://github.com/k-s-h-r/wcag-audit-kit/pull/16)。

タイトルの存在を確認する`2.4.2-01`の現状を測る。タイトルがページの主題を説明するかという意味判断は、このタスクの成績に含めない。

## 作業と成果物

T001の条件を固定し、`benchmarks/run.py collect`のmachineモードと基準`2.4.2`を使って新しいrunを作る。ページごとに既存の1ページ検査を実行し、正常・異常の両方を収集する。観点単位の実行フィルターは現在存在しないため、基準単位の出力から対象行を集計する。

既存のdocument-title出力、期待結果との対応、未出力、誤検出、未確認、全体の採点終了状態を記録する。同じ条件で再実行し、判定の変化と時間を残す。実装・予算・環境を変えた場合は別条件として扱う。

成果物は`validation/development/T002/`の実行記録、各run、対象行と証拠の対応、成績、再実行手順。失敗を修正せずに残し、修正候補をT009へ渡す。

## 完了条件と確認

- T001の全対象行について、判定又は未確認と生の証拠を辿れる。
- タイトルの存在と主題の判断を分け、基準全体を適合にしていない。
- 同じ条件での再実行結果を比較できる。
- 失敗を含めた基準値が固定され、T008とT009が参照できる。

成績が悪くても測定タスクは完了できる。G1達成には選択範囲の誤り・未確認の解消を別途確認する。

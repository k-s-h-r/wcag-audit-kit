# T014：選定したサイトで検証を統合する

状態：指定一覧の機械検査、タイトルの意味比較、実Orcaの通知観察を組み合わせる試験を開始した。開始条件はG2、T011・T012の利用範囲の実証、T013。

実証した手段を組み合わせ、小さなサイト・アプリで依頼から報告まで進める。未実装の全AA基準を一度に完成させるタスクにはしない。

## 作業と成果物

検査担当にはURL、範囲、アクセス条件と必要な手順だけを渡す。採点側が別に持つ対象・状態・問題の一覧を使い、発見漏れ、誤検出、誤った適合、未確認を測る。既知の基準別作業票を渡す試験とは区別する。

URL台帳、選定、ページ担当、機械検査、必要なAI・実SRの追加確認、ページ間・手続き全体の確認、報告までの対応を残す。中断・再開、使用したモデルと環境、費用も記録する。改善に使っていない別の問題での評価を含め、正解を知っていることによる見かけの成功を避ける。

成果物は`validation/development/T014/`の統合試験記録、実AI・実操作の履歴、判定と証拠、採点、各段階の費用と不足する能力の一覧。

## 完了条件と確認

## 担当範囲と引き継ぎ

統合受入を担当し、各タスクの成果物を使う。複数の機能を一度に書き換えるPRにはしない。発見した不備は担当範囲に応じた小タスクへ戻す。

完了時に記載する情報：対象と隔離条件、使用した各実装・環境、各段階の成績と費用、未達の能力、次の開発範囲。

## 別サイトの受入試験

「まちの工作室」の案内、道具の受け取り、来館受付を対象にした。公開資料と許可された操作の案内だけを検査側へ渡した。試験サイトを外部ネットワークなしのコンテナに置き、Chromiumの検査環境からはループバックのサイトへ接続した。モデルは保存済みの本文だけを読む別のコンテナで実行する。採点側が別に正解とアクセス記録を持ち、Orcaは同じ試験サイトに限定したループバック接続で観察する。[ADR 0056](../adr/0056-score-a-blind-site-exercise-with-observed-evidence.md)

別の実キー入力では、4ページともスキップリンクで`MAIN#main`にフォーカスが移った。機械帳票の2.1.1欄の16行は、キー入力前に複数要素へ一致した生成セレクターと、`tabindex=-1`の移動先にEnterやSpaceを試した記録から生じた。元の基準値にはこの16行を残し、収集時の候補選択をT009で修正する。

### 意味と発話の観察

タイトルの比較はCodex CLI 0.167.0-alpha.4、Ollama 0.40.16、Qwen3-VL 4B Instructを使用した。3ページのタイトルと初期表示の本文で、主題と目的を別々に尋ねた。案内ページの照合を1件記録した。工作室ではモデルが「開館日」という題名を適合としたが、案内図を説明する本文の引用が元の証拠と一致せず、判定を保留した。受付ページも本文の引用が一致せず保留した。題名が空の受け取り案内は機械検査で扱った。3回のモデル実行は計296.34秒、入力11,983トークン、出力399トークンだった。

実Orca 51.1とChromium 156.0.8078.79で通知を観察した。独立した対照で、フォーカスしたボタンのSpace入力後に表示と発話を取得した。試験サイトの受付ページと受け取り案内でも、実フォーカスを確かめた上でSpaceを入力した。両ページとも「受付を記録しました。」を表示した。3秒の観察範囲で、受付ページでは通知の発話を取得し、受け取り案内ではSpaceの発話だけを取得した。ブラウザーの操作部にフォーカスが移った試行も保存し、対象ボタンにフォーカスした確認だけを採点へ渡した。

候補抽出は1.40秒、確定一覧の読み込みは0.17秒だった。機械検査は1ページ目の7.96秒、中断までの1.59秒、再開の60.26秒を計測した。保存済み報告の再出力は4ページで7.84秒だった。図の意味、任意のサイトの全操作と全基準の確認は今回の範囲に未確認として残る。

### 独立採点と発話の再試験

入手した証拠を、事前に固定した20観点と別の環境で採点した。初回は期待との一致16件、未確認4件。確定した誤検出と誤適合はいずれも0件で、機械帳票のスキップリンク関係の16行は実入力で確認した別の誤検出として記録した。参照の20観点に含まれないタイトル観察が1件あった。

初回のOrca取得は通知要素に直接ひも付く前後の観察が不足していた。別の実行で、公開ページから確認した`#visit-message`の表示と役割を記録し、実フォーカスを照合してからSpaceを送った。受付の`status`では通知が発話され、受け取り案内では同じ表示が出たが発話はSpaceだけだった。同じ環境の正常対照も確認した。2件を追加できた段階の独立採点は一致18件、未確認2件となった。

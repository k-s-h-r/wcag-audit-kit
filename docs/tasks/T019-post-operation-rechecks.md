# T019 操作後の差分再検査を広げる

状態：PR #75のレビュー待ち。前提：[T017](T017-url-only-exploration.md)の比較結果と、[PR #75](https://github.com/k-s-h-r/wcag-audit-kit/pull/75)の採用。関連：[Issue #69](https://github.com/k-s-h-r/wcag-audit-kit/issues/69)。

初期画面は全体を検査し、操作の後は変化した場所と、影響を受ける要素を中心に再検査する。PR #75はARIA属性名と正の `tabindex` の検査で、変化のない要素の結果を再利用する。

## 作業と成果物

CSSで表れる領域、外部ラベル、離れた場所に表示されるポップアップを、操作前後の証拠から比較する。必要な文脈をルールごとに確かめ、再利用を安全に広げられる候補を選ぶ。

## 完了条件と確認

- 同じ操作・表示幅で全体検査と比べ、問題・通過・判断保留・対象を照合する。影響を判断しにくい場合は全体の観察を使う。
- 調べ直した要素と再利用した要素を追える。画面外や別領域に影響がある例も試験する。
- 対象ルールの再検査が減ったことを記録し、時間や通信の計測とは分ける。

## 担当範囲と引き継ぎ

操作前後の観察と再検査の方針を担当する。T018と `page_explorer` の変更が重なる場合は、共通部分を同時編集しない。原始証拠と比較結果は新規runへ保存する。

# T015：開発タスクを追加・整理するスキルを作る

状態：実装・静的確認済み（PRレビュー待ち）。前提タスク：なし。関連：ADR 0020のタスク管理方式。

追加理由と根拠：利用者から、タスクを追加・分割・整理する開発用スキルを`.agents/skills/`へ作成する依頼があった。既存のT001〜T014は検証能力の測定・改善を担当し、この開発用スキルの作成は含んでいない。

## 作業と成果物

`.agents/skills/wcag-dev-tasks/`へ、スキル本体、明示呼び出し設定、タスクのテンプレートを置く。依頼と実測に基づく追加、重複の確認、分割・統合、採番、前提・合流条件の確認、並行できる担当範囲、PRへの保存を手順にする。

成果物はスキルの3ファイル、新しいADR、利用案内、[確認記録](../../validation/development/T015/README.md)。配布する4スキルに開発用の手順を複製しない。

## 完了条件と確認

- このリポジトリの`.agents/skills/`に必要なファイルがあり、明示呼び出し専用のYAML設定を確認できる。
- 既存タスクとの重複、依存関係、採番、完了条件、共有箇所を確認する手順とテンプレートがある。
- 既存タスクの状態と検証記録を保持し、追加タスクと索引・文書参照に矛盾がない。
- 静的な確認と手順の机上確認を記録し、実ホストや独立したAIの判断は未実証として残す。

## 担当範囲と引き継ぎ

編集範囲は開発用スキル、T015、索引と利用案内、新しいADRと確認記録。検証ランタイム、問題集、期待結果、既存T001〜T014は変更しない。

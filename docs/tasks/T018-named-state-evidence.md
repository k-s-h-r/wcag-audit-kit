# T018：観測した操作後状態を名前付きの採点行へ接続する

状態：実装・限定範囲の再測定完了（PRでレビュー待ち）。前提はT002・T003・T017の実測。起点コードはT017の提案ブランチ。親T009の完了を前提にせず循環を作らない。

## 根拠と成果物

T017の新規runではc09/c10のclick後に画像のaxe違反・通過があるが、採点器は初期ノードだけ読むため2行が未確認になる。全非初期ノードをafter-loadへまとめると、複数回クリックの別状態や無関係な経路を混ぜる。

公開する状態へ既存のactions・assertの書式で経路と到達条件を与え、探索で実際に通った経路と観測条件が一致した証拠だけを名前付き状態へ対応させる。ラベルの設定は新しい操作を実行せず、保留した操作を解放しない。正解の判定・根拠・取得期待は検査側に渡さない。

必要な公開状態のメタデータだけを新しい版へ変更する場合は、入力HTML・素材・全期待判定の不変と旧版との差を示す。T001の計画と旧runは変更しない。新しい条件と実装で同じ10行を測り、名前の誤対応・証拠なし・条件未達・矛盾を成功にしない。

## 完了条件と担当

対応しない経路や古い未ラベルの証拠は未確認のまま、正しい経路と実観測にだけ対応する回帰試験がある。新規runで固定10行と残る意味判断・取得未接続を報告する。G1はT008の帳票確認と実装・問題集の版、PR採用状態を含めて別に判定する。

共有箇所のrunner・core・audit・page_explorerと限定した公開状態のメタデータ、検証記録を担当する。同時編集しない。別worktree・ブランチ・runを使い、validation/development/T018へ保存する。

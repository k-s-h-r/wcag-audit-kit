# T016：「進めて」で開発を継続するスキルを作る

状態：実装・隔離試験確認済み。PR #14採用済み。前提タスク：T015。関連：開発継続の依頼。

追加理由と根拠：利用者がタスクの選択・遂行・追加を人間で管理せず、「進めて」で継続できる運用を希望し、作成を依頼した。

## 作業と成果物

`.agents/skills/wcag-dev/`に開発を継続する手順と明示呼び出し設定を置く。AGENTS.mdから自然な継続依頼に適用し、既存のwcag-dev-tasksを後続整理へ使う。1作業単位、前提待ち、タスクが尽きた場合、PRとマージ、引き継ぎの扱いを定める。

成果物はスキル、利用案内、新しいADR、[確認記録](../../validation/development/T016/README.md)。新しいジョブ基盤や検証ランタイムは作らない。

## 完了条件と確認

- タスクの選択、実行、確認、後続整理と終了の単位を読める。
- 「タスクがない」と「開始できるタスクがない」を区別し、根拠なく追加しない。
- 隔離した環境で独立したAIの動作を確認し、未実施の外部操作を成功扱いにしない。
- 既存の測定条件・原始証拠を保持し、各案内と依存関係が整合する。

## 担当範囲と引き継ぎ

担当は新しい開発スキル、AGENTS、開発手順、ロードマップとタスクの案内、T016、新しいADRと確認記録。T015はマージの事実を照合して進捗を更新する。

作成物は新しいwcag-devと各利用案内。根拠は[確認記録](../../validation/development/T016/README.md)と[ADR 0022](../adr/0022-autonomous-development-workflow.md)を参照する。独立したAIの隔離試験で、タスク追加から文書作成まで進む場面と、前提待ちで依存作業を開始しない場面を確認した。実GitHubの操作と実ホストの自然な呼び出しは別に未実証として残す。開発スキルはmainへ採用済み。実ホストの起動はT004で追跡する。[PR #14](https://github.com/k-s-h-r/wcag-audit-kit/pull/14)

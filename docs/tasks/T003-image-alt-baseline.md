# T003：画像の代替文ルールを機械で測定する

状態：未着手。前提タスク：T001。T002と並行できる。

`1.1.1-01`のうち、既存のimage-alt出力に対応する範囲を測る。画像と代替文の意味の比較や、操作部品全般の名前の正しさを実証したとは扱わない。

## 作業と成果物

T001で固定したページ・状態・対象をmachineモードで収集する。基準`1.1.1`の出力から対象行を集計し、正常例、問題例、未出力をすべて数える。空altの装飾画像を含む例の扱いは、既存の期待結果と機械ルールの適用条件に沿って記録する。

初期状態と操作後に現れる画像を分ける。収集器が証拠を取得できなかった場合と、証拠があるのに採点へ接続されない場合を区別する。現在の自動採点は初期ノードを読むため、操作後の未出力を隠さない。必要な取得期待と、その未接続も記録する。

同じ条件で再実行し、成績の変化と時間を比較する。成果物は`validation/development/T003/`の各run、対象行・証拠の対応、成績、機械で残った問題とAIへ渡す意味判断の一覧。

## 完了条件と確認

- 出力のある対象だけを母数にせず、T001の対象行すべてを集計する。
- 初期・操作後の状態と、機械ルール・意味判断を区別できる。
- 見逃し、誤検出、未確認、取得の不足と採点の不足を追跡できる。
- 同じ条件での再実行記録と、T007・T009へ渡す具体的な不備がある。

基準値の記録完了とG1達成は別に判断する。

## 担当範囲と引き継ぎ

変更先はT003の記録とこのファイル。検出ロジックと期待結果は変更しない。機械出力が足りない箇所を、AIの手入力で埋めて機械の成績にしない。

完了時に記載する情報：起点、計画ハッシュ、run一覧、対象と状態ごとの成績、収集・採点のどちらに問題があるか、残るAI確認。

# T042 帳票に残った移動先を追試し、同じ検査票に証拠を結ぶ

状態は追試、帳票への反映、独立レビューを終え、ドラフトPRで提出。[PR #115](https://github.com/k-s-h-r/wcag-audit-kit/pull/115)

対象は問題集の073・074と3.2.1。T009の指定経路による採点と、T034の文書移動要求の記録を前提に、[VISION](../VISION.md#機械とaiに任せたいこと)にある、証拠が足りない画面に戻って検査を続ける流れを試す。起点は公開PR #111の `405134e`、作業ブランチは `codex/t042-confirm-focus-navigation`。[ADR 0126](../adr/0126-revisit-blocked-focus-navigation.md)

## 完了条件

- 普通のURL入口の帳票と `page-next` から、移動先の表示が不足した観察を両画面幅で見つける。普通のガードが作動した間のHTTP受信を保存する。
- 同じ初期状態、起点、画面幅に戻り、別のChromiumで最初の実Tabを試す。許可した既知のループバックGET、実入力、フォーカス、前後の文書を照合する。
- 対応する同じ検査票に追試を登録し、移動先の表示に関する行だけを解消する。通常帳票で観察、結果、範囲の結論と残件を追える。

## 結果と引き継ぎ

073は両幅で氏名入力欄へのフォーカスにより料金一覧の新しい文書が開いたため、該当箇所を3.2.1の不適合と記録した。074では入力欄への1回のフォーカスの結果を記録し、基準の検査票は未確認とした。073の表示不足2件を解消し、ほかのフォーカス先、探索待ち、他の状態と支援環境に関する確認を残した。[再現と帳票](../../validation/development/T042/README.md)

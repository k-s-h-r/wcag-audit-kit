# 2.4.3 フォーカス順序

入力画面を開いた後、p01.htmlは背景の別操作へ、p02.htmlはモーダル内の氏名欄へフォーカスを移します。単なる氏名・電話欄の順番違いを不適合とはしません。

## 3階層のグローバルメニュー

初期状態からTabで「製品」へ移動してEnter、Tabで「業務支援」へ移動してEnter、Tabで第3階層の「見積管理」へ移動する。ポインターで補わずに実行する。 第2階層を開く直前・直後のactiveElementと、次のTabの移動先を記録する。単に階層が表示されたことを、キーでそこへ到達したことにしない。

| ケース | ページ | 期待結果 | 根拠 |
| --- | --- | --- | --- |
| c03 | [p03.html](public/p03.html) | passed | 第3階層を展開してもフォーカスは開閉ボタンに残り、次のTabで見積管理へ移る。Escapeで開閉ボタンへ戻れる。 |
| c04 | [p04.html](public/p04.html) | failed | 第3階層を開いた直後に、メニューを飛び越えて本文の資料請求#afterへフォーカスを移す。開いた階層の操作から順序を外す。 |

第1階層は「製品」、第2階層は「業務支援」、第3階層は「見積管理」「契約管理」のリンクです。通常のnavと開閉ボタンのパターンで、ARIA menubarの矢印キー仕様は課していません。
